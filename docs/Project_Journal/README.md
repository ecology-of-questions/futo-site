# Project Journal

プロジェクトの歴史そのものを記録する場所。

`docs/` には性質の異なる3種類の記録がある。

| ディレクトリ | 記録すること |
|---|---|
| `Research_Log/` | 思想。ChatGPTとの対話で決まっていく方向性のメモ |
| `Decision_Log/` | 技術。実装上の判断・他に検討した案・その理由 |
| `Project_Journal/` | 歴史。その日、プロジェクトに何が起きたか |

Research Logが「何を考えたか」、Decision Logが「何を選んだか」だとすれば、
Project Journalは「何が起きたか」を残す。1エントリは長くしない。
その日の出来事を短い箇条書きで残すだけでよい。
