## 正式公開に向けた更新(Decision Log 0057)

プロジェクトオーナーから、正式公開に向けた包括的な更新指示を受け、
以下を実装した。

- **ヘッダーナビゲーション刷新**: 「Home / Research」から「研究断面 /
  ふ、とについて / note / お問い合わせ」に変更。ロゴが常にHomeへの
  リンクのため「Home」の文字リンクは削除。Mobile幅では開閉式の
  シンプルなメニューに変更(vanilla JS、キーボード操作・Escape・
  外側クリックでの閉じるに対応)。
- **フッター実装**: これまでプレースホルダーだったFooterコンポーネント
  を実装。サイト名・主要ページへのリンク・note・コピーライトを
  全ページ共通で表示。
- **Home「いま、取り組んでいること」セクション追加**: Research
  Statement抜粋の直後に、問いの生態系・Fieldnote(制作中、リンク
  なし)・研究断面の3項目を、カードを使わず細い罫線と余白だけで
  縦に並べる形で追加。
- **Aboutページ新設**(`/about`): 公開研究室について/研究と実践/
  運営者について、の3セクション。運営者名は実名を追加せず、
  「準備中」と分かる形のプレースホルダーで表示。
- **Contactページ新設**(`/contact`): 送信先(メール/フォームURL)は
  環境変数(`PUBLIC_CONTACT_EMAIL`/`PUBLIC_CONTACT_FORM_URL`)経由で
  設定する構成にし、未設定の場合は「連絡先準備中」とだけ表示する
  (仮の個人情報を作らない)。
- **研究断面01に参考文献・参照資料セクションを追加**: 辞書・
  先行研究・古典資料の3群。既存の本文・図・見出し・URLは変更せず、
  末尾に追記のみ。
- **note用の外部リンク設定**: `PUBLIC_NOTE_URL`環境変数で管理し、
  未設定時はHeader/Footerともに非リンクの「note(準備中)」表示に
  切り替わる。

`npm run build`成功、360px幅での横スクロールなし、キーボードのみで
のメニュー開閉・リンク到達を確認。詳細はDecision Log 0057参照。
