# Home editorial study v0.6

対象はトップページのみ。2026-09-18のオーナー承認済み画像案を起点に、実データで実装する。大きい画像の内容は別途検討。

- 温かい白 #f7f5ef、濃い青 #283f51、細い罫線。配色と寸法は tokens.css の editorial テーマに集約。
- 冒頭は「日々の気づきから、問いが育つ。」と既存の紹介文。
- 「音の道」を主な入口にし、説明は labNotebooks.ts を参照。
- 大きい画像は未決定。現状は仮の抽象線画。index.astro の featureImage を指定すれば差し替え可能。実際の身体譜や研究成果を表したものではない。
- 研究断面は公開済みの最新2件。本棚は読書中の先頭3冊。架空の書籍・記事を掲載しない。
- 本棚は書影のみ。書影が未取得・失敗・JS無効の場合は書名・著者入り仮カバー。表紙の下に重複した書誌情報を置かない。
- 760px以下は縦配置。メニューは既存の900px境界と挙動を維持。
- 研究便りは既存のFormspree送信を維持。Substack連携の変更は今回含まない。
- Header/Footerは既存のロゴとリンクを使用し、Homeだけ横幅・フッター配置を整える。
- 下層ページ、Worker/D1、フォームの送信先、URL、Cloudflare設定は変更対象外。

画像案の交換ノート・関わる等の独立リンクや架空の記事タイトルは採用せず、現在の実装に存在する導線を維持する。
