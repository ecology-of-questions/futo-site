# v0.9 — 全ページeditorial統一

v0.8までのトップを基準とする。紙色・濃紺・細罫線・控えめな見出し・余白を全ページに適用。トップ自体の構成は維持。

- 共通: コンテンツ最大1280px、可変左右余白、ページ見出し24〜36px、本文最大42rem。本文の長さを無理に削らず行長と段落間隔で読む速度を整える。
- 研究断面一覧: 新しい断面から表示、番号を左に添える。本文: 節罫線、読みやすい一列、PCは右に追従目次、スマホは開閉目次。
- 実験室: ノートを罫線で分ける。音の道・Fieldnoteに既存の概念モーションを再利用。リンクと再生ボタンは別要素。
- 音の道詳細: タイトルのすぐ下にスライド。プレイヤー領域は960:569で画面高にも合わせる。コメントリンクと交換ノートを維持。
- 本棚: 状態別の3列棚、カバー下のタイトル重複なし。画像成功時のみ実画像へ切替。画像失敗/JSなしでは仮カバー。リンク先/アフィリエイト開示を維持。
- About/ステートメント/プライバシー: 既存本文を保持。Aboutのみ概念モーション。
- 問い合わせ・本の提案・交換ノート: 入力幅・余白・フォーカス表示を統一。送信先・必須項目・処理は維持。
- Fieldnote Reading: 独立の撮影UIを維持して配色・入力画面を統一、実験室へ戻るリンクと拡大可能なviewport。カメラ実装は変更しない。
- 404も同じテーマ、/supportの既存リダイレクトは維持。

モーションはv3の一度再生・再生ボタン・reduced-motion対応を継承。画像や映像の追加取得は行わない。
