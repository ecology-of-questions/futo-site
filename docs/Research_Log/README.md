# Research Log

プロジェクトオーナーとChatGPT(Creative Director)との対話の中で
決まっていく思想的な背景・方向性を残す場所。

- `Design_Spec/` = 決定済みの設計そのもの
- `Decision_Log/` = その設計を実装がどう解釈し、どう形にしたか
- `Research_Log/` = 決定に至る前の、思想や方向性についてのメモ

Decision Logが「なぜこのコードが存在するのか」を実装側の視点で
記録するのに対し、Research Logは実装より前の、デザイン・思想側の
気づきやメモを記録する。フォーマットは自由。日付ごとに1ファイル。
