# 0180 — Homeの本棚プレビューもテキストのみの行リストに変更

## Decision
2026-09-18、プロジェクトオーナーから、デプロイ済みプレビュー(Home「本棚」プレビュー区画)を見て「ここも画像ではなく、見やすくしたい」との指摘を受けた。`/bookshelf`本体で採用したテキストのみの行リスト(Decision Log 0179)と同じ考え方を、Homeの「いま読んでいる」プレビュー(3冊、`HomeBook.astro`が担っていた色面+縦書きタイトルのカード)にも適用した。

## 採用理由 (Rationale)
`HomeBook.astro`は`/bookshelf`旧実装(Decision Log 0167〜0170)と同じ、色面プレースホルダー+`max-height`制約付き縦書きタイトルのパターンを使っており、同じ見にくさの懸念が当てはまる。`/bookshelf`側で既に「タイトル・著者の罫線区切りリスト」という解決策が承認済みだったため、Home側にも同じ視覚言語を適用し、サイト全体で本の見せ方を統一した。

`HomeBook.astro`はHome以外から参照されていなかったため、置き換えに伴い削除した(不要になったコンポーネントを残さない方針)。

## 他の案 (Alternatives)
Home側だけ書影付きのまま残す案もあったが、`/bookshelf`本体と見せ方が分かれてしまい、「同じ研究室として感じられること」という方針(Decision Log 0177)に反するため見送った。

## 将来の変更可能性 (Future changes)
`book.image`・`book.externalCoverUrl`・`isbn13`データ自体は`src/data/bookshelf.ts`に残っており(Decision Log 0179)、将来書影表示に戻す際はHome側の実装も合わせて検討する。

## Research Context
1つの指摘(本棚が見にくいかもしれない)から、`/bookshelf`本体だけでなくHomeのプレビューにも同じ問題が潜んでいることに気づき、サイト全体で一貫した解決を図った。部分最適ではなく、公開研究室全体の一貫性を保つという姿勢に沿った変更。
