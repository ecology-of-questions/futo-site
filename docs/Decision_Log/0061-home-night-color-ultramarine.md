# 0061. Home夜空背景の色を、プロジェクトオーナー指定の群青に変更する

- 日付: 2026-09-03
- 状態: 上書き済み(→ 0062)。プロジェクトオーナーの追加指示により
  `--color-night`は同じ色相・彩度のまま明度を下げた`#354c7d`に
  変更された。詳細はDecision Log 0062参照。

## Decision

Decision Log 0059で`--color-night`として`#1c2438`(紺)を仮に置いて
いたが、プロジェクトオーナーから具体的なHEX値の指定
(`#4c6cb3`、群青。RGB 76/108/179、CMYK 76/59/8/0)があったため、
`src/styles/tokens.css`の`--color-night`をこの値に変更した。

`--color-paper`(#f7f3ea)とのコントラスト比は、`#1c2438`時点の
約13.9:1から約4.6:1に下がった。WCAG AA基準(通常テキスト4.5:1、
大きな文字3:1)は引き続き満たしているが、AAA基準(7:1)は満たさなく
なった。この変化は、Home Desktop幅の背景色を明るい方向(紺→群青)に
変更した結果として構造的に生じるものであり、プロジェクトオーナーが
色そのものを明示的に指定した以上、その指定を優先した。

## 採用理由

- 色の最終値はDesign Specまたはプロジェクトオーナーの指示で確定する
  という`tokens.css`冒頭の既存方針(「実装者が独自に『見やすさ』
  判断で変更しないこと」)に従い、プロジェクトオーナーが明示的に
  指定したHEX値をそのまま採用した。
- コントラスト比の変化(13.9:1 → 4.6:1)は、変更後もWCAG AAの
  通常テキスト基準(4.5:1)をぎりぎり満たしているため、可読性として
  致命的な水準ではない。ただし、当初(Decision Log 0059)プロジェクト
  オーナー自身が懸念していた「紺地に白文字は見にくいか」という
  論点に関わる数値であるため、Decision Logとして変化の事実を
  記録しておく。

## 他の案

- 検討していない。プロジェクトオーナーからHEX値が明示的に指定された
  ため、実装者側で別の値を提案する場面ではないと判断した。

## 将来の変更可能性

- 実際の画面で「思ったより見にくい」といった声があれば、文字側の
  色(`--color-paper`をより明るい白寄りの値にする、またはコントラスト
  を補う縁取り・影を検討する等)や、背景色そのものの再調整を含めて
  改めて検討する。

## Research Context

「夜空のような青」という当初の発想(Decision Log 0059の起点となった
プロジェクトオーナーの直感)を、より具体的な色指定によって精緻化した
判断。技術的な正しさ(コントラスト比)と、プロジェクトオーナーが
思い描く世界観(群青の夜空)は必ずしも同じ最適解を指さないことがあり、
今回はその調整を数値として記録に残すこと自体が「なぜこの色なのか」
という問いへの応答になる。
