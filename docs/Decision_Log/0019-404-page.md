# 0019. 404ページを、静かなトーンの独立レイアウトとして実装する

- 日付: 2026-08-10
- 状態: 採用中

## Decision

`src/pages/404.astro` を新設した。Astroの規約により、このファイルは
ビルド時に自動的に `/404.html` として出力され、Cloudflare Pagesの
静的サイトで標準的に404レスポンス用ページとして使われる。

見出しは「気づいたら、道に迷っていた。」とし、Heroの見出し
「気づいたら、そこに問いがある。」と同じ「気づいたら、」という
書き出しを踏襲した。本文は「探していたページは、ここにはないよう
です。」「けれど、空の棚を恐れない。それが、この研究室の姿勢です。」
の2行とし、末尾に `ArrowLink` で「Homeへ戻る →」(`/`)を配置した。

レイアウトはHomeの各セクションが使う `ResearchSection` を再利用せず、
`404.astro` 専用のレイアウト(`404.module.css`)を持たせた。

## 採用理由

- 依頼の「エラーを強く出さない、「ふ、と」らしい静かなトーンで(例:
  空の棚を恐れないという方針と同じ姿勢で)」という指示を、Design Spec 8
  (完成度よりも育てられることを優先する。空の棚や"Coming Soon"は隠す
  べき未完成ではなく積極的に使ってよい)にそのまま接続した。「404」
  という記号や「エラーが発生しました」のような文言を画面上に出さず、
  見出し・本文ともに通常の散文として書いた。
- 見出しに「気づいたら、」という書き出しを使ったのは、Hero(Home最初の
  接点)と対になる形で、「見つからないページに迷い込むこと」自体を
  この研究室らしい「気づき」の一つとして扱いたかったため。エラー画面と
  Homeの声のトーンが分断されないようにする狙い。
- レイアウトを `ResearchSection` の再利用にしなかったのは、
  `ResearchSection.astro` 自身のコメントが「Homeを構成する各セクション
  の共通ラッパー」「Heroだけは独自レイアウトのため対象外」と明記して
  いるため。404ページもHomeの一部ではなく独立した着地点であり、Heroと
  同様に専用レイアウトを持たせる方が役割の境界に忠実だと判断した。
  中身の見出し・本文のスタイルは、視覚的な一貫性を保つため
  `ResearchStatement.module.css` の `.heading`(fs-xl, max-width 36rem)・
  `.paragraph`(fs-lg)と揃えた。
- コンテンツが短いページであるため、`min-height: 60vh` と
  `justify-content: center` で縦方向にゆとりを持たせ、ページ全体が
  上部に偏って寂しく見えないようにした。

## 他の案

- **`ResearchSection` をそのまま使う案**: 実装は速いが、
  `ResearchSection.astro` 自身が「Home専用」と明言している境界を
  越えてしまう。今回は見送り、Heroと同じ「独自レイアウトを持つページ /
  セクション」の扱いに揃えた。
- **「404」という数字を小さく残す案**: 一般的な404ページの慣習には
  近いが、「エラーを強く出さない」という今回の依頼と、数字が持つ
  「エラーコード」的な響きが相性が悪いと判断し、本文からは外した
  (ブラウザタブの`<title>`にのみ「ページが見つかりません」という
  文言を残し、機能的な情報としては提供している)。

## 将来の変更可能性

- Header/Footerが実装された場合(現状どちらもTODOプレースホルダー)、
  404ページの縦方向のゆとり(`min-height: 60vh`)は再調整が必要になる
  可能性がある。
- 見出し・本文の文言は今回Claude側の実装判断(依頼内のトーン例からの
  推測)で書いたため、プロジェクトオーナー/ChatGPT側でのレビューを
  経て変更される可能性がある。

## Research Context

「空の棚を恐れない」という方針(Design Spec 8, Decision Log 0004・0009)
は、これまで「まだ用意されていないコンテンツ」に対して使われてきた
考え方だった。今回、その姿勢を「そもそも存在しないURL」という、
研究室の内側ではなく訪問者の道に迷いに対しても同じトーンで応答する
形に広げた。完成していないことも、見つからないことも、隠したり
謝罪したりする対象ではなく、静かに受け止めて次の一歩(Homeへ戻る)を
示すという一貫した態度になっている。
