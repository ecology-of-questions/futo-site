# 0168. 本棚: 書影下のタイトル・著者キャプションを削除

- 日付: 2026-09-17
- 状態: 採用; superseded(→ 0179。2026-09-18、書影グリッド自体を
  テキストのみの行リストに置き換え)
- 関連: Decision Log 0167(この改訂の直前の状態、書影+タイトル・著者
  キャプションのグリッド)。

## Decision

Decision Log 0167でブクログ風の書影グリッドに刷新した直後、プロジェクト
オーナーから「画像下にあるタイトルやちょさめい削除」との指示を受けた。
書影カード下に表示していたタイトル・著者名のキャプションを削除し、
書影のみのカードにした。

## 対応

`src/components/BookshelfShelf.astro`から、各カードの`captionInner`
(`<p class={styles.caption}>`によるタイトル・著者・「持ち寄られた本」
表示)を削除した。あわせて`BookshelfShelf.module.css`の`.caption`・
`.author`・`.contributedTag`ルールを削除し、`.card`は子要素が
`.cover`のみになったため`display: flex; flex-direction: column;`を
`display: block;`に簡略化した。

### アクセシビリティへの対応

キャプションが担っていた「タイトルを可視テキストとして伝える」役割を、
削除したままにせず別の形で維持した。

- `book.image`・`book.externalCoverUrl`がある場合の`<img>`は、これまで
  `alt=""`(装飾扱い、キャプション側にタイトルがある前提)だったが、
  `alt={book.title}`(持ち寄られた本は`alt="{book.title}(持ち寄られた本)"`)
  に変更し、画像自体がアクセシブルネームを持つようにした。
- 画像が無い本の仮カバー(`.coverTitle`)は、`aria-hidden="true"`を外し、
  引き続き可視テキストとして表示する(これがそのカードの唯一の
  テキスト情報になる)。
- 「持ち寄られた本」というキャプションにあった情報は、可視表示からは
  無くなったが、上記の通り`alt`に引き継いだため、情報自体は失って
  いない(スクリーンリーダー利用者には引き続き伝わる)。

## 対応ファイル

- `src/components/BookshelfShelf.astro`
- `src/components/BookshelfShelf.module.css`

`src/data/bookshelf.ts`・`BookActions.astro`・Worker/D1/APIは変更して
いない。

## 確認結果

- mobile(390px)/desktop(1440px)でスクリーンショットを確認し、6冊すべて
  書影(仮カバー)のみのカードになり、下にタイトル・著者テキストが表示
  されないことを確認した。
- Playwrightで`.caption`相当の要素が0件であることを確認した。
- 画像が無い本(現状6冊すべて)の仮カバーに、これまで通りタイトルが
  可視テキストとして表示されることを確認した。
- 「本棚に本を持ち寄る」トグルが引き続き正しく動作することを確認した
  (今回の変更対象外)。
- mobile/desktopとも`document.documentElement.scrollWidth ===
  clientWidth`を確認し、横方向のoverflowが無いことを確認した。
- `npx astro check`: 0 errors, 0 warnings, 1 hint(既存の無関係な
  hint)。
- `npm run build`: 15ページ生成、エラーなし。

## 採用理由

指示通り、書影下の可視テキストを削除してブクログのような「表紙だけが
並ぶ」見た目に近づけた。ただし可視テキストを削除することと、その
テキストが運んでいた情報(タイトル、持ち寄られた本かどうか)を完全に
失うことは別問題と考え、`alt`属性への引き継ぎという形で後者は維持した。
CLAUDE.mdの「実在するものだけを見せる」方針そのものではないが、
「情報を黙って削らない」という、これまでの本棚・実験室の改訂で一貫して
とってきた姿勢に沿った判断。

## 他の案

キャプションのテキストをまるごと削除し、画像の`alt`も空のままにする案も
検討したが、それでは画像が無い本(現状すべて)のアクセシブルネームが
無くなり、スクリーンリーダー利用者にとって単なる色面の羅列になって
しまう。可視表示と情報保持を分けて考え、可視のキャプションだけを削除
することにした。

## 将来の変更可能性

- 実際の書影画像を持つ本が増えてきた際、画像とタイトルの結びつきを
  もう少し明示したくなった場合は、`title`属性やツールチップ的な表示を
  検討する余地がある。
- 「持ち寄られた本」であることを再び可視表示したくなった場合は、
  `.cover`にバッジを重ねる等、キャプション行を復活させない形での
  表現を検討する。

## Research Context

「画像下のテキストを消す」という一見小さな指示でも、それが運んでいた
情報(タイトル、持ち寄られた本かどうか)をどこにも残さず消してしまうと、
見た目の整理と引き換えに研究の記録性を失うことになる。今回`alt`属性への
引き継ぎという形で情報を保持したのは、「公開した瞬間に完成しない」
このプロジェクトが、見た目を変えるたびに過去の情報を少しずつ削って
いくのではなく、表現の器を変えながら中身は保ち続けるという考え方の
一例である。
