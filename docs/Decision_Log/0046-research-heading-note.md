# 0046. /researchページの「研究断面」見出しに、短い説明文を添える

- 日付: 2026-08-17
- 状態: 一部上書き済み(→ 0047)。1行目「完成した研究ではなく、
  その時点で見えているものを記録する。」は削除された。2・3行目は
  そのまま維持。

## Decision

`/research`ページで「研究断面」という見出しが説明なしに登場する、
というプロジェクトオーナーの指摘を受け、見出しの右横(Desktop幅)に
短い説明文を追加した。

```
完成した研究ではなく、その時点で見えているものを記録する。
観察し、記録し、対話し、つくり、また観察する。
その過程を残していくための研究ノート。
```

`research.astro`に`.headingRow`(見出しと説明文を横並びにする
コンテナ)を追加し、`research.module.css`に対応するスタイルを
追加した。Desktop幅(900px以上)では見出しと説明文を横並び
(baseline揃え)、Mobile幅では縦に積む。

プロジェクトオーナーが指定した3行の文章は、そのまま3つの`<p>`
として実装した(Research StatementやResearch Reviewの本文で
採用している「自然な折返しに任せる」方針(Decision Log 0026)とは
異なり、この文章は短い宣言の連なりであり、CLAUDE.mdの
Philosophyセクション自体と同じ「一文一行」のリズムを持つ
性質のものと判断したため)。

## 採用理由

- 「研究断面」はこのプロジェクト固有の用語であり、初見の読者には
  何を指すか伝わらない。見出しのすぐ横に短い説明を添えることで、
  一覧を読み進める前に言葉の意味を掴めるようにした。
- 3行それぞれが独立した短い宣言文であり、1つの文に結合すると
  リズムと意味の切れ目が失われる。Research Statement本文の
  「長い文章を自然に折り返す」方針とは性質が異なるコンテンツと
  判断し、行ごとに独立した要素として実装した。

## 他の案

- 見出しの下に説明文を置く(縦積み)案も考えられたが、
  プロジェクトオーナーから「右横に」という明確な指示があったため、
  Desktop幅ではその通りに実装した。Mobile幅は画面幅の制約上、
  縦積みにフォールバックしている。

## 将来の変更可能性

- この説明文はページ全体(「研究断面」というシリーズ名)の説明で
  あり、01個別の内容の説明ではない。02, 03が追加されても
  変更する必要はない想定。

## Research Context

「研究断面」という言葉そのものが、このプロジェクトの重要な概念
(完成ではなく、その時点の観察を記録する)を体現している。
その考え方を、一覧ページに来た読者へ最初に短く手渡す、という
判断。
