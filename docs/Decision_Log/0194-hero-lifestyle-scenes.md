# 0194 — Heroを「暮らしのなかで、観察し、学び、試す。」という一続きの場に変更(Decision Log 0193を撤去)

ステータス: 一部superseded (→ 0196)。見出し「暮らしのなかで、」・h1の
全文構成という決定自体は継続しているが、ここで実装した「人物1体が
3位置を移動するデスクトップ用アニメーション」と「記号的な単色SVG」は
Decision Log 0196で撤去し、3姿勢常時静止表示+描き込みのある
イラストに置き換えた。本entryは実装当時の記録として残す。

## Decision
プロジェクトオーナーから、トップページHeroの表現をさらに変える指示を受けた。Decision Log 0193で実装した「暮らす　観察　学ぶ　試す」4語の大見出し(色の変化で循環を示す案)をやめ、以下の構成に変更する。

- 大見出しとしては「暮らしのなかで、」だけを表示する。「暮らし」はひとつの工程ではなく、人物のすべての行為を包む時間・場そのものとして扱うため、見出しから切り離した。最初に「暮らす」人物を別場面として置く実装はしない。
- ひとりの人物(短髪・Tシャツ・ジーンズ・スニーカー)が、その一続きの場のなかで「観察する→学ぶ→試す」の3姿勢を移る。歩行アニメーションは実装しない。
- 「観察する」「学ぶ」「試す」は、人物のそばに添える小さな注釈として表示する。
- h1の読み上げ・SEO用テキストは「暮らしのなかで、観察し、学び、試す。」の全文を保つ。

実装は以下のとおり(`src/pages/index.astro` / `src/pages/index.module.css`)。

1. `<h1 id="home-title">`に「暮らしのなかで、」を可視テキストとして持たせ、続く「観察し、学び、試す。」は`.srOnly`で視覚上は隠す(既存の`.srOnly`ユーティリティを再利用)。視覚上は大見出しを増やさない指示を、h1自体は完全な文を保ったまま満たしている。
2. `.heroScene`(`aria-hidden="true"`)に、ひとりの人物のSVG(`.heroWalker`、viewBox `0 0 24 40`)と、3つの注釈`<span>`(`.heroCaption`)を置いた。人物の3姿勢(`.poseObserve`/`.poseLearn`/`.poseTry`)は、それぞれ独立した`<g>`のopacityをcrossfadeさせて切り替える(関節を動かす歩行アニメーションではない)。
   - `.poseObserve`: しゃがんで上体を前に傾け、頭を進行方向・下向きにずらし、地面近くの小さな点(`.walkerMark`)を見る姿勢。
   - `.poseLearn`: 直立し、曲げた腕の先に小さな四角形(`.walkerProp`、ノート/紙)を持ち、それを見る姿勢。
   - `.poseTry`: しゃがんで両腕を地面近くまで伸ばし、2つの小さな四角形(紙片)に両手を添える姿勢。足で蹴る・踏む・またぐような動きは含めていない。
3. 人物の水平移動(`left`)と登場・退出(`opacity`)は`heroWalkerPath`が担当。12秒周期で、観察する(起点)→学ぶ→試す、それぞれ静止する間を置きながら移り、試すのあとはその場でゆっくりopacityを0へフェードアウトし(「姿勢を戻す」)、見えないまま観察するの位置へ戻ってから再びフェードインする。戻り道を示す矢印・円環・ループ線は描いていない。
4. 3つの注釈(`.heroCaption`)は常時表示、既定色は`--color-ink-muted`。人物がその場面にいる間だけ、対応する注釈の色を`--color-ink`にする(`heroCaptionObserve`/`Learn`/`Try`、`heroWalkerPath`の対応する区間と一致させている)。
5. `.heroGroundLine`という1px・`--color-accent-beige`の水平線を人物の足元に1本だけ通し、地面・時間の連続性を示す。工程線・矢印としては使っていない。
6. `prefers-reduced-motion: reduce`では、人物を「観察する」の姿勢・位置で静止表示する。3つの注釈もすべて表示されたまま、「観察する」だけ`--color-ink`に固定する。
7. Heroに既存の再生操作(ボタン等)は無いため、新しい操作UIは追加していない。

## 採用理由 (Rationale)
- 「暮らし」を4語のうちの1語として並べると、暮らし自体がひとつの工程であるかのように見えてしまう。見出しを「暮らしのなかで、」という時間・場の表現に絞り、残る3つの行為(観察する/学ぶ/試す)を人物のそばの小さな注釈に格下げすることで、指示にある「暮らしはすべての行為を包む時間・場である」という構図を素直に実装した。
- 姿勢の切り替えを歩行アニメーションではなくクロスフェードにしたのは、Decision Log 0195(撤去)と同じ理由で、CSSでは異なる`d`パス文字列同士を確実に補間できないため。指示書も「完全な歩行アニメーションでなくてよい」と明記している。
- 人物・注釈のサイズを`--home-hero-words`(見出し用、最大2.5remまで拡大するclamp)に連動させず、固定値(人物の高さ1rem、注釈top位置1.15rem)にしたのは、実装中の検証で判明した制約による。`.heroScene`は`.heroStage`(見出しの行)に対し絶対配置で重ねてはみ出させ、そのはみ出し分を`.intro`のpadding-block(`--home-intro-space`)で相殺する設計だが、このpaddingは761〜800px幅で最小2rem(32px)まで縮む一方、`--home-hero-words`は同じ幅帯でも横方向のvw依存で値が変わり続けるため、見出しサイズに連動させると特定の幅で相殺しきれず研究断面の見出しに人物・注釈が重なってしまうことをPlaywrightで発見した。固定値にすることで、320〜1440pxの全幅で研究断面の開始位置が変わらないことを保証できた。
- モバイル(`.intro`が縦積みになる760px以下)では、`.heroScene`のはみ出しは`.introAside`(「この場所について」)と重なる。ここは`.intro`のpadding-blockを0にし、同じ分だけ`.introAside`にmargin-topを持たせる(padding→marginの付け替え、合計は不変)ことで、Hero全体の高さを変えずに衝突を避けている。

## 他の案 (Alternatives)
- 人物・注釈のサイズを見出しと連動する`--home-hero-words`ベースのclampにする案を最初に試したが、上記の理由(761〜800px幅でpadding-blockの最小値2remを超える)によりHero高さが増える・研究断面の見出しに人物が重なる、という2つの不具合が出たため見送った。
- `.heroScene`を見出しの隣(横並び)に置く案も検討したが、`.intro`が`justify-content: space-between`で`.introAside`と共有する行のため、横に置くと`.introAside`の表示幅を圧迫し、768px幅で「この場所について」が折り返してHero高さが増える不具合が出た(実装中に発見・修正)。最終的に見出しの下に絶対配置で重ねる形に統一した。
- 試すの姿勢は当初、脚を1本前に踏み出す構図だったが、指示書が明確に「足で蹴る、踏む、またぐ、前進して突破するような動きは禁止」としているため、しゃがんで両腕を地面近くまで伸ばす構図に描き直した。

## 将来の変更可能性 (Future changes)
- 人物の姿勢(SVGパス)は`src/pages/index.astro`内の3つの`<g>`だけで完結しているため、絵柄の微調整はここだけで行える。
- 4つ目以降の場面を追加する場合は、`heroWalkerPath`・各`heroPose*`・`heroCaption*`の%区切りを組み替え、位置を`.heroStage`幅の均等N分割にすれば、人物・注釈の対応は崩れない。
- `.heroScene`のはみ出し量(人物の高さ+注釈の行送り)を増やしたい場合は、761〜800px幅での`--home-intro-space`の最小値(2rem)を基準に再計算し、Playwrightで研究断面の開始位置が変わらないことを再検証する必要がある。

## Research Context
「ふ、と」は手順を説明する場ではなく、暮らしの中で探究が息づく様子を見せる場である。4語の見出しを「暮らしのなかで、」という時間・場の表現に絞り、観察する/学ぶ/試すを人物のそばの小さな注釈へ格下げしたことは、「暮らしはひとつの工程ではなく、すべてを包む場である」という指示の意図を、実装のうえでも文字どおり反映した変更である。
