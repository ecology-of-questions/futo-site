# 0043. 研究断面詳細ページの行内で、図版を少し右に寄せる

- 日付: 2026-08-16
- 状態: 採用中(Decision Log 0042の続き)

## Decision

`.row .image`の`margin-inline`を`0`から`var(--space-3) 0`
(左マージンのみ1.5rem)に変更し、図版を表との間に少し余白を空けて
右へ寄せた。プロジェクトオーナーの「図を少しだけ右にずらしたい」
という指示への対応。

## 採用理由

- 図版の列(1fr)は表の列より広いため、図版(max-width: 32rem)を
  そのまま左詰めにすると表とほぼ隙間なく接してしまっていた。
  既存のspacingトークン(`--space-3`)を使って表との間に余白を
  作ることで、2つの要素が視覚的に分離され、「少しだけ」という
  指示に沿う穏やかな移動になる。
- 新しいトークンは追加せず、既存の`--space-3`をそのまま流用した。

## 他の案

- `justify-self: center`や`end`で図版を列内に配置する案も検討したが、
  列の残り幅次第で移動量が大きく変わってしまい、「少しだけ」という
  指示には向かないため、固定のmarginによる調整を選んだ。

## 将来の変更可能性

- さらに右に寄せたい場合は`--space-3`を`--space-4`などに差し替える。

## Research Context

数ピクセル単位の微調整もプロジェクトオーナーの目で確認しながら
進める、という編集フローそのものの記録。
