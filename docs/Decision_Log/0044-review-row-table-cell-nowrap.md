# 0044. 研究断面詳細ページの行内の表で、長い用例セルを1行に収める

- 日付: 2026-08-16
- 状態: 採用中(Decision Log 0042の続き)

## Decision

`.row .table`に対して、`table-layout: fixed`と`font-size: var(--fs-sm)`
を指定し、1列目(「ふと」の用例)に`width: 14.5rem`を明示した。
プロジェクトオーナーの「表の「ふと振り返る」が2行になっているが、
これを1行にした上で、表と図の幅はキープして」という指示への対応。

「ふと立ち止まる、ふと振り返る」というセルが、Decision Log 0042で
表の列幅を20remに絞った際、単語の途中(「ふと振」/「り返る」)で
折り返されてしまっていた。表・図版全体の幅(20rem / 32rem)は
変更せず、列内のレイアウトだけで解決した。

## 採用理由

- `table-layout: auto`(デフォルト)のままだと、列幅はブラウザが
  内容から自動計算するため、狭い表の中でどの列がどれだけ折り返す
  かを直接コントロールできない。`table-layout: fixed`にして
  1列目の幅を明示することで、2列目(身体/知覚/記憶/思考という
  短い単語)に必要以上の幅を渡さず、1列目に幅を回せるようにした。
- 文字サイズを`--fs-sm`(0.875rem)に縮小したのは、`.row`全体の幅を
  変えずに1列目のセル内容(「ふと立ち止まる、ふと振り返る」、
  約14文字)を1行に収めるために必要だったため。この変更は`.row`
  内の表に限定しており(`.row .table`というセレクタ)、section2の
  通常幅の表など、他の`.table`の見た目には影響しない。
- 14.5remという値は、`.row`の1列目の列幅上限(20rem、Decision Log
  0042)の中で、1列目のセル内容が1行に収まる実測値をもとに決めた
  (padding込みで232px、実測した文字幅約199pxに対して余裕を持たせた)。

## 他の案

- `white-space: nowrap`だけを追加する案も検討したが、これは
  列幅を内容に合わせて広げる方向に働くため、表の外側の幅
  (Decision Log 0042の20rem)を超えてはみ出す、または`.row`
  全体の幅がずれてしまう懸念があり、採用しなかった。
- セルのテキスト自体を短縮する(例:「ふと振り返る」を削る)案も
  検討したが、原稿の内容(元原稿の用例)を実装の都合で削ることは
  避けたいため見送った。

## 将来の変更可能性

- 02以降のReviewページで`.row`内に別の表を置く場合、セル内容の
  長さによっては14.5remや`--fs-sm`の組み合わせを再調整する必要が
  ある。

## Research Context

表・図版の外形サイズ(Decision Log 0042・0043で決めた「表と図の
バランス」)を崩さずに、内容の見え方だけを直す、という細部への
配慮。原稿の用例(「ふと立ち止まる、ふと振り返る」)をそのまま
1つの読める単位として提示する。
