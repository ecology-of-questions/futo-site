# 0123. 「いま、取り組んでいること」の「研究断面」本文を改訂する

- 日付: 2026-09-11
- 状態: 採用

## Decision

プロジェクトオーナーから、Home「いま、取り組んでいること」セクション
にある「研究断面」カードの本文の改訂指示を受けた。

修正前: 「そのとき考えていることを、途中からひらく。」
修正後: 「そのとき考えていることを書いて、研究の過程を薄い断面の
ように積み重ねていく。」

「ひらく」(単発の公開行為)から「書いて…積み重ねていく」
(継続的な蓄積行為)へと動詞を変え、「薄い断面のように」という
「研究断面」という名前そのものの比喩を本文に取り込んでいる。

## 対応

`src/pages/index.astro`の`currentWorkItems`配列、`title: "研究断面"`
の`body`を差し替えた。この文言はこの1箇所のみに存在していた
(`/research`ページの見出し説明文等、他の箇所には同じ文言は使われて
いない)。

## 採用理由

指示された文言をそのまま反映した。

## 他の案

なし。

## 将来の変更可能性

「研究断面」という形式自体が今後変化すれば、この説明文も合わせて
見直される可能性がある。

## Research Context

「薄い断面のように積み重ねていく」という言い回しは、「研究断面」が
1回で完結する記事ではなく、同じ研究の異なる時点の断面を積み重ねて
いくものだという位置づけ(Decision Log 0005・0006のResearch State
Model、「出版状態ではなく研究状態」という考え方)を、Home上の短い
紹介文の中でも明確にしている。
