# 0131. /participateのHero・まとめから仮画像プレースホルダーを削除する

- 日付: 2026-09-11
- 状態: 採用

## Decision

プロジェクトオーナーから、`/participate`のHero(「持ち寄る」冒頭)と
「ともに、続けていくために」(まとめ)にあった、中身のない四角い
色面(実在の写真素材が用意できるまでの仮のプレースホルダー)を
削除する指示を受けた。

## 対応

`src/pages/participate.astro`から、以下の2つの`aria-hidden="true"`
装飾要素を削除した。

- Hero: `.heroPanel`(色面のみ、テキストなし)
- まとめ: `.closingPanel`(色面のみ、テキストなし)

いずれもDesign上「将来実際の写真に差し替える想定のプレースホルダー」
だったが、実際の写真素材が未定のまま残り続けていたため、中身のない
色面を残すより、本文を1カラムで見せる方を選んだ。

これに伴い、2カラム分割(テキスト+色面)のためだけに存在していた
ラッパー要素(`.hero`/`.heroText`/`.closing`/`.closingText`)も
撤去し、`何かを持ち寄る`・`持ち寄られたもの`・`本をプレゼントする`と
同じ「見出し+本文を`ResearchSection`直下に並べる」構造に統一した。
`src/pages/participate.module.css`から、完全に未使用になった
`.hero`/`.heroText`/`.heroPanel`/`.closing`/`.closingText`/
`.closingPanel`を削除した。

## 採用理由

指示を字面通りに実装した。ラッパー要素・CSSの削除は、指示自体には
含まれていなかったが、プレースホルダー画像を消すと2カラム分割の
理由が完全になくなるため、不要になったコードを残さないという
方針(CLAUDE.md)に沿って、必要最小限の付随的な整理として行った。
ページ全体のセクション構造が単一パターンに揃ったことで、コードの
見通しも良くなっている。

## 他の案

色面を残したまま何らかの仮アイコンや模様を足す案は検討しなかった
(指示は「削除」であり、代替の装飾を求めるものではなかったため)。

## 将来の変更可能性

将来、Hero・まとめ用の実際の写真素材が用意された場合は、
`<img>`要素と対応するレイアウト(2カラム分割の復活を含む)を改めて
追加する形で対応する。

## Research Context

意味を持たない装飾要素を削除し、テキストと余白だけで構成する判断は、
「余白を思考時間として扱う」「静かな編集的レイアウト」という
Design Spec/CLAUDE.mdの美意識と一致する。中身のない色面を長く
残しておくことは、「完成していないものを取り繕う」ことにもなり
かねないため、今回のように「まだ無いものは無いものとして扱う」
選択は、公開研究室としての誠実さとも整合する。
