# 0035. 研究断面詳細ページのタイトル・本文の文字サイズと行間を調整する

- 日付: 2026-08-15
- 状態: 採用中(Decision Log 0034の続き)

## Decision

`ResearchReviewArticle.module.css`を、プロジェクトオーナーの指示
(「タイトルもう少し文字サイズ小さく。本文の文字サイズを小さくし、
行間も詰めたい」)に沿って調整した。

- `.subtitle`(記事タイトル。Decision Log 0034で主役に据えた要素):
  `--fs-2xl` → `--fs-xl`。
- `.paragraph`・`.list`(本文・箇条書き): `--fs-lg` → `--fs-base`、
  `line-height: var(--lh-body)`(1.9) → `var(--lh-heading)`(1.5)。

`.title`(「研究断面01」)・`.sectionHeading`(「はじめに」等)・
`.table`は変更していない。

## 採用理由

- `--lh-body`(1.9)はサイト全体で「余白=思考時間」という思想の
  もとに定めたゆったりした行間のトークン(Design Spec 10、tokens.css
  コメント)であり、この値自体を変更するとResearch Statement等
  サイト全体の本文行間に影響してしまう。今回の指示はResearch
  Review詳細ページの本文に限定した「行間を詰めたい」という要望
  だったため、`--lh-body`は変更せず、既存の`--lh-heading`(1.5)を
  この文脈で流用する形にした。新しいトークンを追加せず、tokens.css
  の値も変更していない(CLAUDE.md Coding Rules: 「Don't change
  tokens.css values based on "readability"」)。
- フォントサイズも同様に、既存のtokens.cssのスケール
  (fs-base/fs-lg/fs-xl/fs-2xl)の中から1段階小さい値を選んだ。
  新しい中間サイズを追加するのではなく、既存のスケールに収める
  ことを優先した。

## Decision Log 0034との関係

0034で「研究断面01」(通し番号)を縮小し、記事タイトルを主役として
拡大する変更を行ったが、その際の拡大幅(fs-lg→fs-2xl)が大きすぎた
ため、今回さらに1段階(fs-2xl→fs-xl)下げて調整した。0034が定めた
「番号より記事タイトルを優先する」という視覚的な優先順位そのものは
維持している。

## 他の案

(既存トークンのスケール内で1段階ずつ調整する単純な変更のため、
特になし)

## 将来の変更可能性

- 02以降のReviewページも同じコンポーネントを再利用するため、
  自動的に同じ文字サイズ・行間になる。
- さらに調整が必要な場合も、既存のtokens.cssのスケール内で
  対応することを優先する。

## Research Context

「本文の行間を詰めたい」という要望は、Design Spec 10が定めた
「余白を思考時間として扱う」というサイト全体の方針そのものを
否定するものではなく、Research Review詳細ページという特定の
コンテキスト(見出し→本文→箇条書き→表という、原稿由来の構造化された
長文)における読み心地の調整だと理解している。`--lh-body`という
共通トークンを変えずに`--lh-heading`を転用したことで、サイト全体の
思想と、このページ固有の要望の両方に応えられたと考えている。
