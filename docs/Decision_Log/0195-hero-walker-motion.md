# 0195 — Heroを「ひとりの人が暮らしのなかで探究する」モーションに変更(Decision Log 0193を撤去)

## Decision
プロジェクトオーナーから、トップページHeroの表現を大きく変える指示を受けた。Decision Log 0193で実装した「暮らす　観察　学ぶ　試す」を大見出しとして表示し、色の変化だけで4語の順を示すモーションをやめ、代わりに**ひとりの人物の動きそのものをHeroの主役**にする。4語は各場面のそばに添える小さな注釈(説明ラベル)として扱う。

実装は以下のとおり。

1. `src/pages/index.astro`:
   - 大見出しの`<h1>`(1行のテキスト)を撤去。代わりに、人物`.heroWalker`(1つのSVG、viewBox `0 0 24 40`)と、小さな注釈`.heroCaptions`(`<h1>`、読み上げ・SEO用)を`.heroStage`の中に置いた。
   - 人物SVGの中に、4つの場面ぶんの姿勢を`<g>`として重ねている:
     - `.poseWalk`(歩く): 頭(circle)+胴体(ellipse)+腕・両脚(stroke path)。
     - `.poseObserve`(観察する): 上体を前に傾けた曲線の胴体+頭を進行方向・下向きにずらして配置し、屈んで手前を見る姿勢にした。
     - `.poseLearn`(学ぶ): 直立した胴体+曲げた腕の先に小さな四角形(ノート/紙を表す`<rect>`)を添え、手元の小さな紙を見る姿勢にした。
     - `.poseTry`(試す): 腕を大きく前に伸ばし、脚を大きく踏み出す姿勢で、その場から一歩踏み出して確かめる様子にした。
   - `<h1 id="home-title">`は4つの`<span>`(暮らす/観察する/学ぶ/試す)をそのまま子要素に持つ。子要素をすべて`position: absolute`にしているため、h1自体の高さは0になり、視覚上は大きなタイトルに戻っていない(読み上げ・SEO用のh1は維持したまま、指示書の「見た目を大きなタイトルに戻さないこと」を満たす)。

2. `src/pages/index.module.css`:
   - `.heroStage`の高さを`calc(var(--home-hero-words) * var(--lh-heading))`にした。これはDecision Log 0193の大見出しが実際に占めていた1行ぶんの行送りの高さと**完全に同じ式**であり、Heroの合計の高さ・研究断面の開始位置を変えないことをPlaywrightで検証済み(検証・未検証事項参照)。
   - 人物・4つのラベルの水平位置は、`.heroStage`の幅を均等に4分割した位置(12.5%/41.67%/66.67%/91.67%)。
   - 人物の姿勢の切り替えは、関節を回転させるのではなく、姿勢ごとのopacityを`heroPoseWalk`/`heroPoseObserve`/`heroPoseLearn`/`heroPoseTry`という@keyframesで0↔1にクロスフェードさせるだけにした(異なる`d`パス同士をCSSで滑らかに補間する方法が無いため、姿勢は「切り替え」ではなく「重ねてクロスフェード」で実現している)。
   - 人物本体の水平移動(`left`)・登場退出(`opacity`)は`heroWalkerPath`が担当。14秒周期で、暮らす(起点)→観察する(少し立ち止まる)→学ぶ(立ち止まる)→試す(一歩外へ出る)→そのまま右へ歩き去りopacityを0に→間を置く→暮らすの位置まで見えないまま戻り、フェードインして復帰、という一巡になっている。戻り道は線・矢印・円で可視化していない。
   - 4つのラベル(`.heroCaption`)は常時表示、既定色は`--color-ink-muted`(控えめ)。人物がその場に来ている間だけ、その場のラベルだけ`--color-ink`(本文と同じ濃さ)にわずかに濃くする(`heroCaption1`〜`4`、それぞれ`heroWalkerPath`の対応する区間と一致させている)。
   - `.heroCaption`は`.heroStage`の下端から少しはみ出す位置(`top: 100%`)に置いている。このはみ出し分は、`.intro`の`padding-block-end`を`padding-block-start`より1.25rem狭くすることで、レイアウト上の高さには影響しないようにした(はみ出し先の余白を、あらかじめ差し引いておく形)。`@media (max-width: 760px)`で`.intro`が`display: block`に切り替わり`.heroStage`と`.introAside`が縦に積む配置になった際は、この差し引き分と同じ1.25remを`.introAside`のmargin-topとして持たせ、はみ出したラベルと`.introAside`(「この場所について」リンク)が重ならないようにしている(差し引きと追加が相殺し、`.intro`全体の高さは変わらない)。
   - `prefers-reduced-motion: reduce`では、指示書の指定どおり人物を「観察する」の姿勢・その場面の位置(41.67%)で静止表示する。4つのラベルもすべて表示されたまま(観察するのラベルだけ`--color-ink`に固定)。
   - Heroに既存の再生操作(ボタン等)は無いため、新しい操作UIは追加していない(指示書「新たな大きな操作UIは追加しない」に従う)。

3. `src/styles/tokens.css`: `--home-hero-words`のコメントを更新し、現在の役割(大見出しのフォントサイズではなく、Heroの高さ・人物のサイズ算出の基準)を反映した。値自体は変更していない。

## 採用理由 (Rationale)
- 「研究の手順を説明する場ではない」という指示に対し、円環図・工程図・矢印を使わず、ひとりの人物が場面を通り過ぎるという「経験されるリズム」だけで往復を伝える構成にした。文字を主役から補助へ格下げしたのは、この設計判断を最も直接的に反映する変更である。
- 姿勢の切り替えを関節回転ではなくクロスフェードにしたのは、CSSでは異なる`d`パス文字列同士を確実に補間できないため。姿勢ごとに完結した静止イラストを4枚用意し、重ねてopacityだけ動かす方式なら、ブラウザ間の差異なく確実に同じ見た目になる。
- Heroの高さを変えないという制約に対しては、旧見出しが実際に占めていた高さの式(`--home-hero-words × --lh-heading`)をそのまま流用することで、目分量ではなく数式レベルで一致を保証した。
- ラベルがHeroの下端からわずかにはみ出す設計にしたのは、人物+ラベルを本当にゼロ増分の高さに収めようとすると、モバイル幅(--home-hero-wordsの下限、1.35rem)ではラベル(12pxフォント)が事実上表示できないほど窮屈になるため。はみ出し分をあらかじめ`.intro`のpadding側から差し引くことで、Hero全体の高さは変えずに済ませた。

## 他の案 (Alternatives)
- 4つの姿勢を1つの人物リグ(関節ごとのgroupをtransform: rotate()で動かす)として実装する案も検討したが、CSSキーフレームで4つの離散した姿勢+その間の自然な補間を同時に満たすには、各関節の回転角度をすべて手動で計算・同期する必要があり、実装・保守コストに対して見た目の向上が見合わないと判断し、クロスフェード方式を採用した。
- ラベルをHeroの高さの中に完全に収める(はみ出させない)案も検討したが、モバイル幅で人物・ラベルとも読める大きさを保てなくなるため見送った。
- 「新しい再生操作を追加する」案は、指示書が「新たな大きな操作UIは追加しない」と明記しており、既存の再生操作も存在しないため見送った。

## 将来の変更可能性 (Future changes)
- 5つ目以降の場面・姿勢を追加する場合は、`heroWalkerPath`・各`heroPose*`・`heroCaption*`の%区切りを組み替える。位置は`.heroStage`幅の均等N分割にすれば、人物・ラベルの対応は崩れない。
- 人物の姿勢(SVGパス)は`src/pages/index.astro`内の4つの`<g>`だけで完結しているため、絵柄の微調整はここだけで行える。

## Research Context
「ふ、と」は手順を説明する場ではなく、暮らしの中で探究が息づく様子を見せる場である。文字による大見出しから、ひとりの人物の動きへとHeroの主役を替えたことは、「説明しすぎない」「訪れた人が自分を重ねられる余地をつくる」というCLAUDE.mdの一貫した方針をより直接的に体現する変更である。

## 検証・未検証事項
- `npx astro check` / `npm run build`: エラーなし。
- Playwright(Chromium)で320/375/390/430/768/1440px幅を検証:
  - 横方向のoverflowが無いことを確認。
  - `main`(このHero変更前)と比較し、`#research-title`の開始位置が全幅で一致(差0px、丸め誤差のみ)することを確認——Heroの高さが増えていないことの直接的な証拠。
  - `.heroCaption`のはみ出しが`.introAside`(「この場所について」)と重ならないこと(モバイル幅でギャップ約5.6px)を確認。
- `prefers-reduced-motion: reduce`で、人物が「観察する」の姿勢・位置に静止し、4つのラベルがすべて表示され、「観察する」だけ濃い色になることを確認。
- JavaScript無効でも、人物・4つのラベルが表示されることを確認(モーションはCSSのみで実装、JS不使用)。
- `prefers-reduced-motion: no-preference`で、暮らす→観察する→学ぶ→試すの順に人物の位置・姿勢・アクティブなラベルが対応して切り替わることを、複数の時点のスクリーンショット・computed styleで確認。
- 4つの姿勢イラストをズームスクリーンショットで目視確認し、頭・胴体・腕・脚が識別できることを確認(観察する・学ぶは初版で頭部と胴体が視覚的に融合していたため、形状を調整して再確認済み)。
- 実機(iOS Safari等)での目視確認、Cloudflare Preview環境での確認はPRコメントに記録する。
