# 0079. カーソル追従の光を、範囲を狭く・強度を強く調整する

- 日付: 2026-09-04
- 状態: 採用中(0078を一部上書き)

## Decision

プロジェクトオーナーから、Homeページに試験導入したカーソル追従の光
(Decision Log 0078)について「もう少し範囲の狭い光がいい。光の強さを
強くしたい」というフィードバックを受け、`CursorGlow.module.css`の
数値を調整した。

- 直径: 36rem → 18rem(半分)
- 中心の不透明度: 0.14 → 0.4

追従の仕組み・有効条件(Desktop幅かつマウス操作可能な環境限定、
Homeページのみ)は0078のまま変更していない。

## 採用理由

- 「範囲が狭く、強度が強い」方向への調整は数値(width/height/margin
  とradial-gradientの不透明度)を変えるだけで実現でき、構造面の変更は
  不要だった。
- 円のサイズと中心のマイナスマージン(中心点をカーソル位置に合わせる
  ためのオフセット)は必ず連動するため、半径を変える際は対応する
  `margin`の値も同時に変更する必要があった(width/height=18rem→
  margin=-9remの半分)。

## 他の案

- 不透明度だけ上げてサイズは変えない案も考えられたが、指示に
  「範囲の狭い光」と明記されていたため、サイズも縮小した。

## 将来の変更可能性

- さらに調整が必要であれば、`.glow`の`width`/`height`/`margin`
  (常に連動)と、`radial-gradient`の不透明度・フェードアウト位置
  (現在は70%地点で透明)を変更する。

## Research Context

数値の微調整であっても、プロジェクトオーナーの「もう少し」「強く」
という感覚的なフィードバックをその都度反映し、Decision Logに残す
ことで、なぜ今の値になっているかが後から追える。この積み重ねが、
「感触を確かめながら育てる」という進め方そのものの記録になる。
