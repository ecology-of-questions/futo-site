# 0124. 「関わる」パネルの本文を改訂する

- 日付: 2026-09-11
- 状態: 採用

## Decision

プロジェクトオーナーから、Home「研究便り・関わる」セクションにある
「関わる」パネルの本文の改訂指示を受けた。

修正前:
```
気になる本や情報を寄せる。
同じ本について話す。
一緒に試したり、場所や知識を持ち寄ったりする。
いろいろなかたちで、この研究に関わることができます。
```

修正後:
```
「ふ、と」では、自分とは異なる他者や、これまで知らなかった世界との
出会いを大切にしたいと考えています。そのため、さまざまな方法で
研究に関わる場を設けています。
```

「本を寄せる/話す/持ち寄る」という関わり方の列挙から、「ふ、と」が
なぜ他者との関わりを設けているのか(異なる他者・知らなかった世界との
出会いを大切にする、という研究の姿勢)を先に述べる文章に変わっている。

## 対応

`src/pages/index.astro`の「関わる」パネル本文を差し替えた。従来は
`<div class={styles.panelBody}>`内に`<br />`区切りの列挙文と2つ目の
`<p>`をまとめていたが、新しい文章は1段落のため、隣の「研究便り」
パネル(`<p class={styles.panelBody}>...</p>`)と同じ構造に揃え、
単一の`<p>`要素に変更した。`index.module.css`の`.panelBody`/
`.panelBody p`スタイルはどちらの構造にも対応しているため、CSS側の
変更は不要だった。

## 採用理由

指示された文言をそのまま反映した。構造を「研究便り」パネルと揃えた
のは、単一段落になった時点で`<div>`+複数`<p>`の入れ子を維持する
理由がなくなったため(不要な入れ子を残さない、というシンプルさの
原則)。

## 他の案

なし。

## 将来の変更可能性

「関わる」の具体的な参加方法(本を寄せる・話す・持ち寄る等)が
再び本文に必要になれば、構造を`<div>`+複数`<p>`に戻す可能性がある。

## Research Context

Decision Log 0120で「研究を支える」から「関わる」への置き換えを
決めた際は「どう関われるか」を列挙する文章だったが、今回の改訂は
「なぜ関わりをひらいているか」という研究姿勢そのものを先に語る形に
なっている。異なる他者・知らなかった世界との出会いを大切にする、
という姿勢は、Research Statement(「気づいたら、そこに問いがある」)
が語る「問いが生まれ、育っていく過程」を、他者との関わりという
側面から言い換えたものと位置づけられる。
