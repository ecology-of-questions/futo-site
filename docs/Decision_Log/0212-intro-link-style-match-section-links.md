# 0212. 「この場所について」を、研究断面「すべて読む→」と同じ見た目に揃える

- 日付: 2026-09-27
- 状態: 採用

## Decision

プロジェクトオーナーから、モバイルのnote.comアプリ内ブラウザで見たスクリーンショットとともに、「この場所について」を「研究断面」の「すべて読む→」と同じラインに変更できるかという相談を受けた。配置(人物イラストの行のすぐ下/横、Decision Log 0204〜0206)ではなく、見た目のスタイルを「すべて読む→」「本棚へ→」(`.sectionHead > a`)に揃えたいという趣旨であることを選択肢で確認した。

`src/pages/index.module.css`に`.introLink`を新設し、`src/pages/index.astro`の「この場所について」リンクに`class:list={[styles.textLink, styles.introLink]}`で追加適用した。

- `font-family: var(--font-sans)`(以前は指定なしでbody既定の`--font-body`明朝体を継承していた)
- `font-size: var(--home-label-size)`(12px。以前は`.textLink`の`--fs-sm`=14px)
- `border-bottom: none`(以前は`.textLink`の常時下線、`--color-accent-beige`の1px)
- `:hover`時のみ`text-decoration: underline`(「すべて読む→」のhover時下線と同じ挙動)

配置(人物イラストの行のすぐ下/横に置く)自体は変更していない。`.textLink`クラス自体(「続きを読む」「実験をのぞく」等、ページ内の他のリンクで共有)は変更せず、「この場所について」だけに追加クラスでスコープした。

## 採用理由

- `.sectionHead > a`と実際の計算スタイルを比較し、font-family・font-size・border-bottomの3点が異なっていたことを確認した。この3点だけを`.introLink`で上書きすることで、狙った見た目に最小限の変更で揃えられる。
- `.textLink`クラス自体を変更しなかったのは、このクラスがページ内の他のリンク(「続きを読む」「実験をのぞく」等)でも共有されており、直接変更すると意図しない箇所まで見た目が変わってしまうため。

## 他の案

- 配置自体を「研究断面」の見出し行に移動する案(選択肢として提示)も検討されたが、プロジェクトオーナーが「見た目のスタイルを揃える」を選んだため、配置は変更しなかった。

## 将来の変更可能性

- 「この場所について」の見た目をさらに調整したい場合は、`.introLink`のルールを変更するだけでよい。`.textLink`(他のリンクとの共有部分)には影響しない。

## Research Context
「この場所について」は、探究の入り口を示す控えめな案内であり、「すべて読む→」「本棚へ→」と同じ、セクションの終わりに添える軽やかなナビゲーションとして扱う方が、Heroの主役(人物イラスト・見出し)を邪魔しない。見た目を軽くしたことは、この場所のクリック可能な要素の中での重み付けを、他のセクション末尾のリンクと揃える調整である。

- スクリーンショットで、モバイル・デスクトップとも意図した見た目(小さめの文字、常時下線なし)になっていることを確認した。
