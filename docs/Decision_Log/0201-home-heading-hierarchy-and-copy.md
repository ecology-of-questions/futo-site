# 0201 — モバイルHero見出しの縮小、トップページの見出し階層の統一、散歩譜の紹介文更新

## Decision
プロジェクトオーナーから、トップページ(モバイル中心)について次の指摘を受けた。

1. モバイル版のHero見出し「暮らしのなかで、」をもう少し小さく。
2. 「研究断面」「本棚」「実験室」を同じ文字サイズに。「散歩譜」(実験室セクション内の個別ノート名)は「実験室」より文字サイズを小さめに。
3. 実験室カードの一文「誰かの気づきを、音から辿る。」を「散歩中の気づきを動きから辿る。」に。
4. `/participate`(実験室ページ)の散歩譜の説明文を「散歩しながら、どこで立ち止まり、何に気付いたのか。その人の注意の道筋を音符のように辿れる方法を考えています。」に。

対応した変更は以下のとおり。

**1. モバイルHero見出しを縮小**
`src/styles/tokens.css`の`--home-hero-words`(Hero見出し専用のclamp())を`clamp(1.35rem, 0.78rem + 2.9vw, 2.5rem)`から`clamp(1.2rem, 0.68rem + 2.5vw, 2.2rem)`に変更した。768px以上は`index.module.css`の`@media (min-width: 768px)`で別のclamp()(Decision Log 0199)に上書きされるため、この値は実質モバイル専用。390px幅で約23.8px→約20.6px(約13%減)になる。デスクトップの見え方(768px以上)は変更していない。

**2. 見出し階層の統一(実験室↔散歩譜)**
以前は「研究断面」「本棚」(`.sectionHead h2`、`--home-section-title`)と「実験室」(`.eyebrow`、`--home-label-size`=0.75rem固定)でサイズが異なり、さらに「散歩譜」(`.featureCopy h2`、`--home-feature-title`)が「研究断面」「本棚」よりも大きいという、他の2セクションと逆転した階層になっていた。

- `index.module.css`に`.featureEyebrow`を新設し、「実験室」の`<a>`に`class:list={[styles.eyebrow, styles.featureEyebrow]}`で適用。`font-size: var(--home-section-title)`として「研究断面」「本棚」と同じ大きさにした(`.eyebrow`は「研究断面 01」やニュースレターの見出し上のラベルにも使われている共通クラスのため、そちらは変更せず、実験室だけに追加クラスで対応した)。
- `.featureCopy h2`(散歩譜のタイトル)を`--home-feature-title`から`--home-article-title`(研究断面の個別レビュータイトルと同じ、`--home-section-title`より一段小さいトークン)に変更した。
- 結果、390px幅で「研究断面」「本棚」「実験室」はいずれも22.4px、「散歩譜」は16.8pxに、1440px幅ではいずれも28.8px、「散歩譜」は20pxになった。「実験室」は section 見出し、「散歩譜」はその中の個別アイテム名という、研究断面([研究断面]→個々のレビュー記事)・本棚([本棚]→個々の本)と同じ主従関係になった。
- `--home-feature-title`トークン自体は`tokens.css`に残した(参照が無くなっただけで、値を書き換えたわけではないため)。

**3・4. 文言修正**
- `src/pages/index.astro`のトップページ実験室カードの一文を「誰かの気づきを、音から辿る。」→「散歩中の気づきを動きから辿る。」に変更した。
- `src/pages/participate.astro`の`landingDescriptions["oto-no-michi"]`(`/participate`ページの散歩譜の説明文)を「誰かがどこで立ち止まり、何に気づいたのか。その人の注意の道筋を、音から辿る方法を考えています。」→「散歩しながら、どこで立ち止まり、何に気付いたのか。その人の注意の道筋を音符のように辿れる方法を考えています。」に変更した。この文言はトップページには表示されず、`/participate`一覧ページのみで使われる。

## 採用理由 (Rationale)
- Hero見出しの縮小は、モバイルで見出しの存在感が人物イラスト・行為名に対して大きすぎるという指摘への直接対応。デスクトップは別のclamp()で既に上書きされているため、モバイル専用の値だけを変更すれば済んだ。
- 「実験室」を「研究断面」「本棚」と同じ見出しサイズにする際、既存の`.eyebrow`クラス自体を変更すると「研究断面 01」やニュースレターの小さなラベルまで大きくなってしまうため、`.featureEyebrow`という追加クラスで実験室だけをスコープした。共通クラスを直接変更する案より変更範囲が狭く、既存の他の用途に影響しない。
- 「散歩譜」のサイズを、新しい値を作らず既存の`--home-article-title`(研究断面の個別記事タイトルと同じ役割のトークン)に合わせたのは、「実験室セクション見出し→個別ノート名」という関係が「研究断面セクション見出し→個別レビュータイトル」の関係と構造的に同じであるため。新しいトークンを増やさず、既存のスケールをそのまま再利用した。

## 他の案 (Alternatives)
- 「実験室」の見出しサイズを`<a>`のまま`--home-section-title`に固定値で直接指定する案も考えたが、後から「研究断面」「本棚」側のサイズを変える際に3箇所を個別に直す必要が生じるため、同じトークンを参照する形にした。
- `--home-feature-title`トークンを`tokens.css`から削除する案も検討したが、値そのものを書き換えたわけではなく、単に参照が無くなっただけであり、将来別の用途で使う可能性もあるため、削除はせず残した。

## 将来の変更可能性 (Future changes)
- 「実験室」「散歩譜」の相対サイズは、`.featureEyebrow`(`--home-section-title`)・`.featureCopy h2`(`--home-article-title`)の参照先トークンを変えるだけで調整できる。
- Hero見出しのモバイルサイズは`--home-hero-words`のclamp()値を変えるだけで調整できる(768px以上は別のclamp()のため影響しない)。

## Research Context
「実験室」は「研究断面」「本棚」と並ぶ、このサイトの3本柱のひとつである。見出しの大きさが柱ごとに揃っていないと、同じ重みの場所として読み取りにくくなる。今回、実験室の見出しを他の2つと揃え、その中の個別ノート名(散歩譜)を一段小さくしたことで、「セクション→個別アイテム」という一貫した情報の階層をサイト全体で保てるようになった。また、散歩譜の紹介文を「音」から「動き」「音符」という言葉に調整したことは、身体の動き・注意の軌跡を辿るという散歩譜の探究の核心を、より具体的な言葉で伝えるための調整である。
