# 0175 — Homeの見出し・説明をコンパクトにする

## Decision
2026-09-18の実機スクリーンショットへのオーナーフィードバックを反映。
- 重複した「公開研究室ふ、と」を削除。
- 見出しを「日々の気づきから、問いを育てる。」へ変更。
- スマホで導入・音の道の見出しを24pxへ縮小（PCは36px・32pxまで）。
- 導入の説明段落を削除し、「この場所について」リンクを維持。
- 音の道のHome向け説明は「誰かの気づきを、音から辿る。」の一文。canonical dataと詳細ページの本文は維持。
- 意味が不明瞭だった仮線画を撤去。featureImage未指定時は画像枠自体を出さない。
- 研究断面の表示は維持。
- 背表紙の実写真は未提供。bookshelfPhotoの任意URLで、撮影された本棚写真を表示できるようにした。画像未提供時は既存の本表示を維持する。

## 採用理由
スマホの初期画面が見出し・説明だけで埋まっていた。見出しの縮小と説明の整理で、実際の研究断面への距離を短くする。

## 他の案
文字サイズだけの縮小では説明の重複が残る。仮線画の意味を文章で補う案は、さらに説明を増やすため不採用。

## 将来の変更可能性
音の道の主画像と背表紙写真は、オーナーからの素材受領後に組み込む。背表紙写真のaltは写っている本に合わせる。

## Research Context
「問いを育てる」というオーナーの表現を尊重し、活動へ直接触れられる入口にする。

0174およびDesign Spec v0.6の導入コピー・大きい見出し・仮線画は、この決定で置き換える。
