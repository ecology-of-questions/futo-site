# 0042. 研究断面詳細ページの行内で、表を狭く・図版を大きく調整する

- 日付: 2026-08-16
- 状態: 採用中(Decision Log 0041の続き)

## Decision

Decision Log 0041で導入したRowBlock(表・図版の横並び)の列比率を
変更した。`ResearchReviewArticle.module.css`の`.row`を
`grid-template-columns: 1fr auto`から`minmax(0, 20rem) 1fr`に変更し、
表の列を20rem上限の狭い固定幅、図版の列を可変幅(1fr)にした。
`.row .image`のmax-widthも18rem→32remに拡大した。
プロジェクトオーナーの「表を小さく、画像を大きく」という指示への対応。

## 採用理由

- 表・図版の「主役」を図版側に寄せる調整であり、列サイズの
  数値だけを変更すれば済むため、RowBlockの構造自体(Decision Log
  0041)は変更していない。
- 表の列を`minmax(0, 20rem)`にしたことで、表がその列の中で
  最大20remまでしか広がらず、余った横幅は自動的に図版側の列
  (1fr)に回る。図版側は32remを上限として、その1fr列の中で
  可能な限り大きく表示される。

## 他の案

(列比率の数値調整のみのため、特になし)

## 将来の変更可能性

- 表のセル内容が増えた場合、20remでは窮屈になる可能性がある。
  その際は表側の上限を再調整する。
- 02以降のReviewページで同じRowBlockを使う場合も、内容の分量に
  応じて列比率を都度調整することを想定している(固定値ではなく、
  ページごとに`.row`のバリエーションを増やす可能性がある)。

## Research Context

図版(概念図)を表(データの整理)より視覚的に優先させることで、
「まず全体像を直感的につかみ、必要なら表で詳細を確認する」という
読み方を誘導する狙いがある。細かな調整もプロジェクトオーナーの
判断に委ねる、というこのプロジェクトの編集フローに沿った変更。
