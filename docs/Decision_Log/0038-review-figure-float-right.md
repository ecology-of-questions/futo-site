# 0038. 研究断面詳細ページの図版を、セクション右上に回り込み配置できるようにする

- 日付: 2026-08-16
- 状態: 採用中(Decision Log 0037の続き)

## Decision

`ImageBlock`型(`src/types/researchReview.ts`)に、任意の
`float?: "right"`フィールドを追加した。これを指定した図版は、
Desktop幅(900px以上)ではセクション右上にfloatし、後続の段落が
左側に回り込む。Mobile幅では通常通り中央配置(`.image`相当)に戻る。

研究断面01のセクション3「「ふと」は何を修飾しているのか」の図1
(`figure-1.svg`)を、このセクションの先頭ブロックに移動し、
`float: "right"`を指定した。プロジェクトオーナーからの「3章の
右上に配置することは可能?」という依頼への対応。

実装上、`.section`をDecision Log 0034以来の`display: flex;
flex-direction: column;`から通常のブロックフロー(`display: block`)
に変更した。floatはflexアイテムには効かない(仕様上、flexアイテムの
floatは無視される)ため、回り込みを実現するにはセクションを通常の
フローに戻す必要があった。ブロック間の余白は、flexの`gap`の代わりに
`.section > * + * { margin-top: var(--space-3); }`で揃え、視覚的な
間隔は変えていない。`.table`には`clear: both`を付け、floatした図版の
高さに関わらず表が常に次の行から始まるようにした。

## 採用理由

- `float`を`ImageBlock`の任意フィールドとして追加することで、
  既存の図版(中央配置)の挙動は変えず、必要な箇所だけ回り込み
  配置を選べるようにした。02以降のReviewページで別の図版を
  追加する際も、必要に応じて選択できる。
- floatの幅を28rem(中央配置時)ではなく18remに絞ったのは、
  本文の折返し列が狭くなりすぎて読みにくくなるのを避けるため。
  Decision Log 0031が目指した「画面をいっぱいに使う」方針は
  段落の折返しに関する決定であり、floatによって一時的に本文の
  実効列幅が狭まること自体は、この特定の図版配置のための
  レイアウト上のトレードオフとして許容した。
- 表(table)は列幅が固定的で、float済みの図版の隣で折り返すと
  レイアウトが崩れやすいため、`clear: both`で常に図版の下に
  表示されるようにし、可読性を優先した。

## 他の案

- `.section`をflexのまま維持し、図版と後続段落だけを別の
  ブロックフローコンテナで包む案も検討したが、`ContentBlock`の
  フラットな配列という現在のデータモデル(Decision Log 0030)を
  崩さずに済む方法として、セクション全体をブロックフローに
  切り替える方を選んだ。

## 将来の変更可能性

- 02以降のReviewページでも同じ`float`フィールドが使える。図版の
  縦横比や周囲の文章量によっては、floatの幅(18rem)を図版ごとに
  調整できるようにする(数値ではなくプリセットのサイズを選べる
  ようにする、など)必要が出てくる可能性がある。
- floatを使う図版が増えた場合、`.section`のブロックフロー化が
  他の表示(リストや引用との間隔など)に影響しないか、都度
  確認する。

## Research Context

「本文の中に図版が浮かんでいる」のではなく「本文が図版を
避けながら流れていく」という配置は、テキストと図版が同じ
思考の流れの中にあるという感覚に近い。Design Spec 10の
「余白を思考時間として扱う」という思想を、今回は余白ではなく
回り込みという形で本文と図版の関係性に反映した。
