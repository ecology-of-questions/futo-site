# 0047. /researchページの説明文から1行目を削除する

- 日付: 2026-08-17
- 状態: 採用中(Decision Log 0046を一部上書き)

## Decision

Decision Log 0046で追加した3行の説明文から、1行目
「完成した研究ではなく、その時点で見えているものを記録する。」を
削除した。プロジェクトオーナーの「全部トル」という指示への対応。
現在は以下の2行のみ表示している。

```
観察し、記録し、対話し、つくり、また観察する。
その過程を残していくための研究ノート。
```

`research.astro`の`.note`内から該当の`<p>`要素を1つ削除しただけで、
`research.module.css`側の変更はない。

## 採用理由

プロジェクトオーナーによる編集判断。「完成/未完成」を説明的に
述べる1文を削り、「観察→記録→対話→つくる→また観察する」という
行為そのものと、それを記録する「研究ノート」という位置づけの2行に
絞ることで、より簡潔な説明になった。
