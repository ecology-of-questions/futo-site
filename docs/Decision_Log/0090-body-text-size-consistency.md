# 0090. 本文フォントサイズを`--fs-base`に統一する(Research Statement・Contact・404)

- 日付: 2026-09-04
- 状態: 採用中(Decision Log 0074の「将来の変更可能性」で予告されていた対応)

## Decision

プロジェクトオーナーから、公開サイト(futo-site.pages.dev)のスクリーン
ショットとともに「全体的に文字サイズルールが曖昧。特にトップページの
ここが大きすぎる」との指摘を受けた(該当箇所はHome「RESEARCH
STATEMENT」抜粋の本文)。サイト全体のfont-size指定を洗い出したところ、
「本文(段落)」の役割で`--fs-lg`(20px)を使っている箇所が3つ残っている
ことが分かった。

- `src/components/ResearchStatement.module.css`の`.paragraph`
  (Home抜粋・Research Statement全文ページ両方)
- `src/pages/contact.module.css`の`.body`(お問い合わせページ導入文)
- `src/pages/404.module.css`の`.body`(404ページ本文)

これに対し、サイト内で最も多く使われている「本文サイズ」
(`--fs-base`、16px。Hero本文、About本文、研究断面詳細ページの本文、
Home「いま、取り組んでいること」の説明文などが該当)に、この3箇所を
揃えた。

これはDecision Log 0074(Aboutページの本文サイズを`--fs-lg`から
`--fs-base`に揃えた際の記録)の「将来の変更可能性」で「Contact・
Research Statement・404ページの`--fs-lg`使用箇所も、将来『揃えて
ほしい』という指摘があれば同様に見直す」と明記していた対応そのもの。

## 採用理由

- 0074時点でAboutページだけを対象にしたのは、その時点の指摘が
  About限定だったため。今回はサイト全体を見た指摘のため、同じ理由
  (「本文」という役割は`--fs-base`に統一する)で残り3箇所も揃えた。
- `--fs-lg`(20px)は、CurrentWorkListの`.itemTitle`(項目見出し)など
  「見出し・強調」の役割で使われている一方、`--fs-base`(16px)は
  純粋な「本文段落」の役割で使われている、という暗黙の使い分けが
  サイトの大部分で既に成立していた。今回の3箇所は、その使い分けから
  外れた古い実装(それぞれ別のタイミングで作られたページ)が
  残っていたことが原因だった。

## 他の案

- 検討なし。Decision Log 0074が既に予告していた対応をそのまま
  実施した。

## 将来の変更可能性

- 今回で「本文の役割には`--fs-base`を使う」という暗黙のルールが
  サイト全体で統一された。今後新しいページ・コンポーネントを追加する
  際も、本文段落には`--fs-base`を使うことを既定とする。
- 見出し・小見出し・強調的なリード文など「本文ではない」役割で
  `--fs-lg`を意図的に使いたい場合は、その旨をコメントで明記すること
  (CurrentWorkList `.itemTitle`のように)。

## Research Context

Decision Log 0074の時点で既に「将来揃えてほしい指摘があれば見直す」
と書き残していたことが、今回の指摘への対応を素早く、かつ一貫した
理由付けで行うことを可能にした。過去の判断とその理由をDecision Log
に残しておくことの価値が、実際に数週間後の別の指摘に対して発揮された
例である。
