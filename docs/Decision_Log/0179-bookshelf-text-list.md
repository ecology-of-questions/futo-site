# 0179 — 本棚をテキストのみの行リストに変更

## Decision
2026-09-18、プロジェクトオーナーから「本棚に表紙を入れたかったが見にくいかもしれない」という相談を受けた。書影を実際に入れた場合(3列グリッド)・入れない場合(色面+縦書きタイトルのプレースホルダー)双方のモックアップを作って検討した結果、どちらも採用せず、タイトル・著者だけを罫線区切りの1行リストで見せる形に変更した。Decision Log 0167〜0170で採用した「ブクログ風の書影グリッド」を置き換える。

## 採用理由 (Rationale)
- 実書影を入れる案: モバイル3列グリッドでは1枚が100px前後まで縮み、表紙の絵柄・タイトルが判別しにくくなる懸念があった。
- 書影なし(色面+縦書きタイトル)の案を検証中、既存実装に`.coverType > span`の`max-height: 80%`制約により、長いタイトル(「生きていること――動く、知る、記述する」等)で縦書き文字が複数列に折り返され、重なって読めなくなる見た目の不具合を発見した。短いタイトルでは問題が目立たないため、これまで見過ごされていた。
- テキストのみの行リストは、タイトルの長さに関わらず横書きで自然に折り返され、上記の不具合が構造的に起きない。罫線区切りは、当ページが以前(Decision Log 0154)採用していた行リストと同じ考え方への回帰でもある。

## 他の案 (Alternatives)
- 実書影+2列グリッド(カードを大きくする): 1画面に見える冊数が減り、「本棚に並ぶ」密度感が薄れるため見送った。
- 色面プレースホルダーを維持しつつ`max-height`制約を外して縦書き崩れだけ直す案: 縦書きタイトルの折り返し先が本によって不揃いになり、カードの高さも本ごとにバラつくため、グリッドとしての整列が崩れる。今回はテキストリストへの変更で、この種の見た目の不安定さごと解消する方を選んだ。

## 将来の変更可能性 (Future changes)
書影(`book.image`・`book.externalCoverUrl`・Open Library Covers API経由の取得)・`tone`・ISBN(`book.isbn13`)は、`BookshelfShelf.astro`の表示からは参照しなくなったが、`src/data/bookshelf.ts`・`src/types/bookshelf.ts`からは削除していない。実在する書誌情報であり、将来「本棚らしい見た目」を再検討する際にすぐ使える状態を残した。

## Research Context
「見にくいかもしれない」という懸念に対して、実装してから初めて気づくのではなく、モックアップとPlaywright検証で先に確認し、既存実装の縦書きタイトル崩れという具体的な不具合まで発見できた。デザインを完成させてから公開するのではなく、育てながら疑わしい点は都度検証する、という本スタジオの姿勢に沿った進め方だった。
