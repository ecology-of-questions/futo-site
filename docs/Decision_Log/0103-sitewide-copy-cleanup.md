# 0103. サイト全体の文章整理(Research Statement以外)

- 日付: 2026-09-09
- 状態: 採用

## Decision

プロジェクトオーナーから、Research Statement以外のページ・セクションの
文章について、重複・説明過多・AIっぽい抽象表現を減らし、短く具体的で
自然な文章に整えるよう指示を受けた。対象は以下の4ファイル。

### 1. `src/pages/index.astro`(トップページ)

- 「いま、取り組んでいること」の導入文(Research Statementとほぼ同内容
  の再説明)を削除し、見出し直後にカード一覧を続けた。
- Researchカード(問いの生態系)・Research Reviewカード(研究断面)の
  本文を、何を調べ・考えているかが分かる具体的な文章に差し替えた。
- 「一緒に試す」(OPEN PRACTICE)の本文3段落を全面的に整理した。
  「観察、記録、対話、制作」のような列挙表現・Research Statementと
  重複する言い回しをやめ、「歩く。音を聴く。身近なものを眺めてみる。」
  のような具体的な行為で書き直した。

### 2. `src/pages/research.astro`(研究断面)

- ページ冒頭の説明文(「観察し、記録し、対話し、つくり」の列挙)を、
  「研究の途中で考えたことを、その時点の断面として残しています。」
  という具体的な文章に差し替えた。
- 研究断面01・1.5の紹介文を、論文要旨調から、内容を想像しやすい
  文章に差し替えた。各記事本文(01.astro・1-5.astro)を確認し、
  新しい紹介文が本文の内容と齟齬がないことを確認済み。

### 3. `src/pages/about.astro`(ふ、とについて)

- 冒頭Lead文(Research Statementとほぼ同内容の再説明)を、「研究の
  途中をひらいておくための小さな公開研究室」という文章に差し替えた。
- 01(公開研究室として)・03(運営者について)の本文を、具体的な
  文章に差し替えた。03からは「大学や研究機関には今のところ所属せず」
  という所属の不在を強調する表現を削除した。
- 02(研究と実践)の本文も短縮したが、この本文の下にある円環図は
  `aria-hidden="true"`の装飾要素で、スクリーンリーダー利用者には
  本文がラベル(観察する/気づく/記録する/対話する/つくる・試す)の
  唯一の情報源になっている(Decision Log 0094時点の設計)。そのため、
  短縮後の文章にも5つの語が一通り含まれるよう、「対話する」→「誰かと
  対話する」、「つくる・試す」→「道具をつくって試す」という形で
  指示の文体を保ちながら調整した。図・座標計算・レイアウトは変更して
  いない。

### 4. `src/pages/contact.astro`(お問い合わせ)

- 冒頭を、「ふ、ととは何か」の再説明ではなく、問い合わせ内容の
  具体例(聞いてみたいこと・一緒に試してみたいこと・取材や協働の
  相談)を示す文章に差し替えた。
- お問い合わせ内容欄の補足文を短縮した。
- フィールドラベル・選択肢・送信ボタン・送信結果メッセージ・送信処理
  ・プライバシー注記は、指示にある「フォーム付近の説明文」には
  該当しないと判断し、変更していない。

### 対象外

Research Statement本文・見出し(`index.astro`内`<ResearchStatement>`)、
記事本文(`research/reviews/*.astro`)、デザイン・レイアウト・背景・
フォント・ナビゲーション構造は、指示により変更していない。

## 採用理由

- 複数ページで「ふと」「問い」「公開研究室」の説明が繰り返され、
  訪問者が同じ内容を何度も読まされる状態になっていた。Research
  Statementに一本化することで、各ページは「そこで何をしているか」を
  具体的に示す役割に絞れる。
- 「観察・記録・対話・制作」のような列挙、「〜していきます」の
  連発、対句的な言い回しは、研究計画書的な硬さ・AIが書いたような
  印象につながっていた。指示に沿って具体的な行為・自然な言い回しに
  置き換えた。

## 他の案

- About 02の本文を指示の文言(「対話する」「つくる・試す」を含まない
  簡潔な案)そのまま採用する案もあったが、円環図のアクセシビリティ
  (装飾要素のため本文がラベルの唯一の情報源)を優先し、5語を残す形に
  調整した。

## 将来の変更可能性

- 各ページの文章は今後も改訂されうる。Research Statementとの重複が
  再発しないよう、新しい文言を追加する際は「ふ、ととは何か」の説明を
  そのページで再度書かないことを基本方針として引き継ぐ。

## Research Context

「ふ、ととは何か」という定義的な説明をResearch Statement1箇所に
集約し、他のページは実際の活動(何を読み、観察し、記録しているか)を
語る場にしたことは、研究室の思想を繰り返し説明するのではなく、
「実際に何をしているところなのか」を訪問者が具体的に思い描けるように
する試みである。
