# 0200 — 「試す」の姿勢を、試行錯誤している感じが出るよう修正

## Decision
main のHero(`HeroWalkerFigure.astro`)について、プロジェクトオーナーから「試すだけ試してる感がない。あれこれ試行錯誤しているような感じが欲しい」という指摘を受けた。人物イラスト全体の描き直しではなく、`poseTry`(右側の「試す」の姿勢)のみを修正した。人物の配置・色・サイズ・観察する/学ぶの姿勢・見出し・モーションの時間構成は変更していない。

修正前の`poseTry`は、両腕を体の脇に下ろし、左右対称に小さな長方形(prop)を1つずつ持つ構成だった。左右対称で静止した「2つを比べて持っているだけ」の見た目になり、指摘のとおり「試している最中」の動きや積み重ねが伝わりにくかった。

以下のとおり変更した。
- 前側(手前)の腕を、体の脇に下ろした状態から、肘を曲げて対象物を顔の高さまで持ち上げ、検分しているような形に変更した。
- 持ち上げた手の位置に、少し傾いた小さな長方形(prop)を1つ配置した。今まさに試している対象物として描いている。
- 後ろ側の腕は変更せず、体の脇に自然に下ろしたままにした(以前そこに持たせていたpropは外した)。
- 足元の左右に、傾きの異なる小さな長方形を1つずつ追加した。既に試して置かれた(観察するの姿勢で使っている`figMark`の足元の点と同じ発想の)過去の試行の跡として描いている。

## 採用理由 (Rationale)
- 「あれこれ試行錯誤している感じ」を、新しいアニメーションや工程UI(矢印・番号・進行バー)を追加せずに伝える方法として、(1)今まさに手に取って検分している対象物、(2)その手前に既に試して脇に置かれた対象物、という「時間の積み重ね」を1枚の静止イラストの中に共存させる構成にした。動きを追加するのではなく、静止した1枚の中に「すでに何度か試された」という痕跡を残すことで表現している。
- 対象物を1つに絞り、足元に過去の試行を2つ置いたのは、詰め込みすぎるとこのHero全体の抑制されたトーン(装飾を増やさない、工程図にしない)から外れるため。既存の`poseObserve`が足元に小さな点(`figMark`)を1つ置いている前例があり、そのスケール感に合わせた。
- 後ろ側の腕からpropを外したのは、両手にモノを持たせたままだと以前と同じ「左右対称に何かを持っている」印象に戻ってしまい、「今、手前の1つに注意が向いている」という読み取りが弱くなるため。

## 他の案 (Alternatives)
- 姿勢全体(頭・髪・胴体・脚)を描き直す案も検討したが、指摘は「試す」の腕・手の使い方に対するものであり、観察する/学ぶとの統一感(髪型・体格・服装)を保つため、既存の頭部・胴体・脚のパスは変更しなかった。
- 足元の過去の試行を3つ以上に増やす案も検討したが、Heroの人物イラストはもともと小さく表示されるため、増やしすぎると小さい画面で単なるノイズに見える懸念があり、2つに留めた。

## 将来の変更可能性 (Future changes)
- 足元の過去の試行の数・傾き・持ち上げた対象物の位置は、`HeroWalkerFigure.astro`の`poseTry`内の`rect`要素の`x`/`y`/`transform`を調整するだけで変えられる。
- 将来「試す」の姿勢自体をさらに描き直す場合も、他の2姿勢とのバランス(髪型・体格・服のシルエット)を保つことが前提になる。

## Research Context
「ふ、と」における「試す」は、一度で正解にたどり着く工程ではなく、いくつかのやり方を手に取っては置き、また別のものを手に取るという、暮らしの中の地道な繰り返しである。今回の修正は、その繰り返しの痕跡(足元に残る過去の試行)と、今まさに向き合っている対象(持ち上げた手の中のモノ)を1枚の静止イラストの中に共存させることで、「試す」を単発の行為ではなく、探究のリズムの一部として見せる調整である。
