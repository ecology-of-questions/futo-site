# 0034. 研究断面詳細ページの文字サイズを入れ替え、記事タイトルを主役にする

- 日付: 2026-08-15
- 状態: 採用中

## Decision

`ResearchReviewArticle.module.css`の`.title`(「研究断面01」)と
`.subtitle`(記事の実質的なタイトル。研究断面01の場合
「「ふと」という日本語について ― 人と世界との関係が変化する瞬間 ―」)
の文字サイズを入れ替えた(プロジェクトオーナーの指示: 「研究断面01の
文字サイズを下げて、タイトルの文字サイズ大きくしたい」)。

- `.title`: `--fs-2xl` → `--fs-lg`。あわせて`opacity: 0.7`を追加し、
  通し番号としての控えめな役割を視覚的にも示す。
- `.subtitle`: `--fs-lg` → `--fs-2xl`。`opacity: 0.75`だった指定を
  外し、`font-weight: 500`・`line-height: var(--lh-heading)`を
  明示して、実質的な見出しとして扱う。

DOM構造(`<h1>`が`.title`、`<p>`が`.subtitle`)は変更していない。
あくまで見た目のサイズ関係だけを入れ替えている。

## 採用理由

- 「研究断面01」は連番としてのラベルであり、読者が読みたいのは
  その先にある実際のテーマ(「『ふと』という日本語について」)である、
  という考え方は、Decision Log 0033で`/research`一覧ページに
  適用したのと同じ考え方(番号を小さく・タイトルを主役にする)である。
  今回の変更は、その考え方を詳細ページ側にも一貫させたものと
  言える。
- DOM上の見出しレベル(`.title`が`<h1>`)はそのまま残しているため、
  スクリーンリーダー等での文書構造(「研究断面01」がこのページの
  h1である)は変わらない。視覚的な優先順位だけを、実際に読みたい
  情報(記事のテーマ)に合わせた。

研究のテーマそのものが目に入るべき」という一貫した優先順位が、
一覧ページと詳細ページの両方に適用された。
