# 0088. Mobileメニューアイコンの枠線を撤去する

- 日付: 2026-09-04
- 状態: 採用中(Decision Log 0087を一部上書き)

## Decision

Decision Log 0087でMobileメニューボタンを「メニュー」という文字
ラベルから3本線のハンバーガーアイコンに変更したが、プロジェクト
オーナーから「3本線を四角で囲わないで。ダサい」との指摘を受けた。
アイコンに差し替えた後もボタン自体には文字ラベル時代の枠線
(`border: 1px solid var(--color-accent-beige)`)・角丸
(`border-radius: 2px`)が残っていたため、これを撤去し、アイコン
のみをそのまま表示する形にした。

- `src/components/Header.module.css`の`.menuToggle`から
  `border`・`border-radius`を削除(`border: none`を明示)。
- `padding`も、枠線ボタンとしての余白(`var(--space-1)
  var(--space-2)`)から、アイコンの周囲に最低限のタップ領域を
  確保するだけの`var(--space-1)`(上下左右均等)に調整した。

## 採用理由

- 枠線・角丸は元々「メニュー」という文字ラベルを囲むボタンとして
  必要だった装飾で、アイコンに差し替えた後も残っていたのは
  Decision Log 0087の実装時の見落とし。アイコン単体であれば
  枠で囲む必要がなく、Headerの他の要素(ロゴ・ナビゲーションリンク)
  も枠なしのため、統一感の面でも枠を外す方が自然だった。

## 他の案

- 検討なし。指摘の通り枠線を外すだけで解決する単純な修正だった。

## Research Context

Decision Log 0087の「静かなトーンに調和する見た目」という意図を、
実装の見落とし(不要な枠線の残存)によって十分に体現できていなかった
点を、プロジェクトオーナーからのフィードバックで修正した。小さな
指摘を都度反映していくプロセス自体が、この研究室の「観察」の
姿勢を実装作業にも反映させている。
