# 0174 — Homeを実データによる編集的レイアウトへ

## Decision
オーナーが画像案を評価し、Astra側で既存コードを改修→Claude Codeで取り込む方針を選択したため、main ec5e1d7を基準にトップを改修。Design Spec v0.6-home-editorial を追加。トップに限り0150の構成を置き換える。大きい画像は仮置き。

## 採用理由
部分的な文言指示の往復から、実データ・実画面のコードで確認できる工程に変更する。活動への入口を先に見せ、同じカードで全コンテンツを均一化しない。

## 他の案
既存Heroと3入口の余白だけの調整、サイト全体の作り直し。前者では承認された方向性に届かず、後者は機能移行の範囲が過大。

## 将来の変更可能性
主画像は featureImage で交換する。オーナーの確認後に下層へテーマを展開する。研究便りの配信基盤変更は独立した作業とする。

## Research Context
完成した成果だけでなく、つくっている途中のノートと読書・研究断面へ入りやすい公開研究室を目指す。

## Scope / validation
編集テーマは body[data-theme="editorial"] に限定。本文データ、ルート、Worker、D1、Cloudflare設定は維持。検証結果は同梱の IMPLEMENTATION.md を参照。

## Status update
導入コピー・見出しサイズ・仮線画の方針は superseded (→ 0175)。研究断面・テーマの限定適用等は維持。
