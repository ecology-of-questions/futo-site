# 0105. カーソル追従の光・ふと現れる光を、ライトトーンでも見えるようにする

- 日付: 2026-09-10
- 状態: 上書き済み(→ 0106。点滅して見える指摘を受け配合比率を調整
  したが、最終的にプロジェクトオーナーの判断で光の演出自体を撤去した)

## Decision

2026-09-10のサイト全体配色変更(Decision Log 0104)で、背景を
`--color-night`(濃紺)から`--color-paper`(白に近い色)に変更した際、
以下の2つの光の演出が事実上見えなくなっていた。

- `NightBackground`の「ふと現れて消える光の粒」(Decision Log 0059〜)
- `CursorGlow`の「カーソル追従の光」(Decision Log 0078〜0079)

いずれも元は「白系の淡い色」を濃紺の上に重ねることで光って見える
設計だったため、地の色自体が白系になったライトトーンでは、白の上に
白を重ねているのとほぼ同じになり、視認できなくなっていた。

プロジェクトオーナーから「カーソルに合わせて動く光と、じんわりと
ふとを体現する光を戻したい」との指示を受け、両方の光をライトトーン
の上でも見えるように作り直した。

### 方針転換: 明るさの差 → 色相の差

濃紺背景では「明るさの差」(暗い背景に明るい光)で光を表現できたが、
`--color-paper`(`#fafaf7`)は`#ffffff`にごく近く、これ以上明るい色を
重ねてもほぼ差が出ない。そのため、明るさではなく**色相の差**で光を
表現する方針に転換した。

サイトで唯一はっきりした彩度を持つ`--color-accent-blue`
(`#365f78`)を、`color-mix(in srgb, var(--color-accent-blue) N%,
var(--color-paper))`で`--color-paper`に薄く溶かし、それを光の中心色
として使った。新しいHEX値を決め打ちせず、既存トークンから算出する
方針(Decision Log 0094など)は維持している。

- `NightBackground`の`.light`: `color-mix(..., var(--color-accent-blue)
  30%, var(--color-paper))` を中心色に、70%地点で完全に透明になる
  radial-gradient。ピーク不透明度(`--light-peak-opacity`、既定0.85・
  `.gradient`配下0.55)は変更していない。
- `CursorGlow`の`.glow`: `color-mix(..., var(--color-accent-blue) 25%,
  var(--color-paper))`を中心色にした。旧実装は`rgba(...,0.4)`で
  グラデーション自体にアルファ値を持たせていたが、`color-mix()`は
  不透明な色を返すため、透明度の管理を`.glow[data-visible="true"]`
  側の`opacity: 0.4`に移した(視覚的な強さは変更前とほぼ同じになる
  よう調整)。

いずれもDOM構造・アニメーションの仕組み(`lightPulse`のkeyframe、
`requestAnimationFrame`によるカーソル追従処理)自体は変更していない。

## 採用理由

- 「今の青はアクセントとして残してください」(Decision Log 0104の
  元指示)という方針に沿い、サイトで唯一の彩度を持つ色をそのまま
  「光」の表現にも転用することで、新しいトークンを増やさずに済んだ。
- 明るさではなく色相で見せる方式は、地の色が`#ffffff`に極めて近い
  ライトトーンの制約(これ以上明るくできない)の下で、光を「静かに
  だが確かに」見せるための現実的な選択肢だった。
- スクリーンショットで確認した結果、`opacity`をアニメーションの
  ピーク時(0.85)またはカーソルオン時(0.4)まで上げても、彩度の
  低い柔らかな水色の滲みとして見え、「静かなトーンを保つ」という
  サイト全体の方針を損なっていない。

## 他の案

- `--color-ink`(濃いチャコール)を薄く溶かした「影」のような表現も
  検討したが、「光」という演出の名前・コメント・ふとという瞬間性の
  イメージ(Decision Log 0059)に対し、影よりも色味のある光の方が
  合っていると判断した。
- 光の色をトークン化されていない新しい色(例: 金色・クリーム色)に
  する案も考えられたが、「サイト全体で使う色を極力絞る」という
  今回の配色変更の方針(Decision Log 0104)に反するため見送った。

## 将来の変更可能性

- 色相の強さ(color-mixの割合)は、プロジェクトオーナーの実際の
  見た目のフィードバックによって今後調整する可能性がある
  (Decision Log 0079のカーソル光強度調整と同じ性質の、感覚的な
  微調整になりうる)。
- 将来的に写真・本の表紙等のメディア要素が追加された際、背景の光の
  演出との相性を改めて確認する必要がある。

## Research Context

「ふと」という一瞬の気づきを、地の色そのものが変わっても同じ強さで
体現し続けられるようにした変更である。表現の手段(明るさ→色相)は
配色の制約に応じて作り替えたが、「ふと現れて、いつの間にか消える」
という体験そのもの、そしてサイトを訪れた人がカーソルを動かすたびに
静かに反応する感触は、そのまま引き継いでいる。
