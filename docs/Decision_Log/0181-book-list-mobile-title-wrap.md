# 0181 — 本のタイトル・著者行、モバイルで縦積みに変更

## Decision
2026-09-18、テキストのみの行リスト(Decision Log 0179・0180)をモバイル実機で確認したところ、「調査的感性術」のようなタイトルが、著者名との横並びレイアウトのために不自然な位置で改行される(「調査的」で改行され「感性術」だけ次の行に残る)問題が見つかった。`/bookshelf`(`BookshelfShelf.module.css`)・Home本棚プレビュー(`index.module.css`)の両方で、760px以下のモバイル幅ではタイトル・著者を横並び(baseline)ではなく縦積みに変更した。

## 採用理由 (Rationale)
横並びレイアウトでは、著者名(`flex: 0 0 auto`)が固定幅を取るため、タイトル(`flex: 1 1 auto`)に残る幅が本によって不均等になり、特にタイトルが4〜6文字程度で著者名が長い場合に改行位置が不自然になる。縦積みにすればタイトルは行の全幅を使えるため、改行が必要な場合も自然な位置になる。

## 他の案 (Alternatives)
著者名を短縮・省略する案は、実在する著者名を勝手に削ることになるため見送った。`white-space: nowrap`でタイトルの改行自体を禁止する案は、長いタイトル(例:「生きていること――動く、知る、記述する」)で横overflowを起こすため見送った。

## 将来の変更可能性 (Future changes)
デスクトップ・タブレット幅(760px超)では引き続き横並び(baseline)のまま。将来的に著者名が非常に長い本が増えた場合は、この閾値やレイアウトを再検討する。

## Research Context
実装直後の目視確認だけでは気づきにくい、実際のタイトル・著者名の組み合わせによる崩れを、公開後の実機フィードバックから発見し反映した。完成を待たず、公開しながら都度直していくという本スタジオの姿勢に沿った修正。
