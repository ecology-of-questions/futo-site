# 0208. OGP画像を、現在のトップページHero構成に作り直す

- 日付: 2026-09-27
- 状態: 採用
- 関連: 0082(初版作成)、0110(ライトトーン配色への作り直し)

## Decision

プロジェクトオーナーから、URLシェア時のプレビュー画像(`public/images/ogp/default.png`)を作り直したいという相談を受けた。旧画像はResearch Statementの見出し「気づいたら、そこに問いがある」+汎用タグライン「世界を観察するための、研究と実践。」のみのシンプルな構成で、2026-09-27時点でトップページHeroが大きく作り直されている(暮らしのなかで、観察し、学び、試すの人物イラスト、Decision Log 0193〜0206)ことを反映していなかった。方向性を確認したうえで、「現在のHero構成を反映」する案を採用した。

### 対応

- 新しい`default.png`(1200×630)を作成した。構成は、ロゴ(`public/images/logo/logo.svg`をそのまま使用)、Hero見出し「暮らしのなかで、」、観察する/学ぶ/試すの3人の人物イラスト(`HeroWalkerFigure`の3姿勢のSVGパスをそのまま複製)とキャプション、トップページの実際のmeta descriptionと同じタグライン「個人の探究をひらき、誰もがふらっと立ち寄り、ともに探究を深められる場です。」を縦に並べた。
- 配色は現在Home(`theme="editorial"`)が使っている値をそのまま使用した: 背景`#f7f5ef`、見出し・人物イラスト`#283f51`、キャプション・タグライン`#586570`。
- Decision Log 0110と同じ手順(Playwrightで1200×630の2倍解像度・2400×1260でHTML/CSSをレンダリングし、Lanczosで1200×630にダウンサンプル)を踏襲した。生成用のHTML/JSはスクラッチ領域で作業し、リポジトリにはコミットしていない(過去のOGP画像作成時も同様)。
- 見出し・タグラインのフォントは、当初サイト本体と同じく見出しに`--font-body`(Hiragino Mincho ProN/Yu Mincho)相当のセリフ体を使っていたが、プロジェクトオーナーから「フォントが違う」「タグラインと見出しのフォントを揃えて」という指摘を受け、両方とも`--font-sans`(Hiragino Kaku Gothic ProN/Yu Gothic)のゴシック体に統一した。見出しの文字サイズも同時に縮小した(60px→46px)。
- `DefaultLayout.astro`の`og:image`参照を`?v=2`から`?v=3`に更新した。X(Twitter)・Facebook・LINE・Slack等はOGP画像をURL単位でキャッシュするため、ファイル名(URL)を変えないと中身を差し替えてもプラットフォーム側に古い画像が残り続ける(favicon修正時・Decision Log 0110と同じ対応)。

## 採用理由

- 「現在のHero構成を反映」を選んだのは、トップページのHeroが一連の改修(Decision Log 0193〜0206)を経て、サイトの「顔」として最も作り込まれた部分になっており、URLシェア時のプレビューもそれに合わせるのが最も一貫性があるため。
- 見出し・タグラインのフォントを統一したのは、プロジェクトオーナーからの直接の指摘に基づく。レンダリング環境にHiragino Mincho/Yu Minchoに相当する日本語セリフ体フォントが無く、フォールバック先の見た目がタグラインのゴシック体と揃わず、ちぐはぐに見えていたため、見出し側をゴシック体に合わせて統一した。
- 人物イラストはSVGパスをそのまま複製する形にした(`HeroWalkerFigure`コンポーネントをOGP画像生成のためにインポートする仕組みは作らず、静的なHTMLに直接埋め込んだ)。OGP画像生成は現状ページのビルドパイプラインに組み込まれておらず、単発のスクリプトで完結させる方が、既存のPlaywright検証の手順(このセッション内で繰り返し使っている手法)にも合致するため。

## 他の案

- OGP画像をビルド時に自動生成する仕組み(Satori等)も、Decision Log 0110で検討済みだったが不採用としており、今回も1枚の共通画像を手動更新する運用を続ける方針は変えていない。
- 見出しのフォントをセリフ体のまま維持し、Webフォント(Noto Serif JP等)をこの画像生成のためだけに追加で取得する案も考えられたが、依存関係が増えるうえ、サイト本体の見出しも実際には環境によってフォールバックする可能性がある(`--font-body`のGoogle Fonts的な自己ホストはされていない)ため、素直にプロジェクトオーナーの指摘通りゴシック体に統一した。

## 将来の変更可能性

- サイトの配色トークン(`editorial`テーマ)が変わった場合は、この画像も合わせて作り直す必要がある(自動追従しない静的アセットである点はDecision Log 0110から変わっていない)。
- Hero見出し・人物イラストの構成が今後変わった場合も、同様に作り直しが必要。

## Research Context

URLシェア時のプレビューは、多くの訪問者が実際のページを開く前に最初に目にする「顔」である。トップページHeroに込めた「暮らしのなかで、観察し、学び、試す」というリズムを、シェアされた瞬間にも同じ姿で伝えられるようにしたことは、コンテナ(Hero UI)の変更をコンテンツ(共有プレビュー画像)にも一貫して反映するという、Decision Log 0110と同じ姿勢の延長である。
