# 0062. Home夜空背景の群青を、黒寄りに調整する

- 日付: 2026-09-03
- 状態: 採用中(Decision Log 0061の色指定部分を上書き)

## Decision

Decision Log 0061でプロジェクトオーナー指定の`#4c6cb3`に変更した
`--color-night`を、プロジェクトオーナーの追加指示(「もう少し黒よりに
するとどう？」)を受けて`#354c7d`に変更した。

`#4c6cb3`と同じ色相(約221°、青)・彩度(約40%)を保ったまま、
明度のみをHSLで50% → 35%に下げた値。`--color-paper`(#f7f3ea)との
コントラスト比は約4.6:1から約7.6:1に改善し、WCAG AAA基準(7:1)を
再び満たす。

## 採用理由

- 色相・彩度を変えずに明度だけを操作したのは、「群青」という
  プロジェクトオーナーが指定した色の方向性(Decision Log 0061)を
  保ったまま、「黒寄りに」という今回の追加指示に応えるため。
  色相や彩度まで動かすと、指定された群青とは別の色になってしまう。
- 結果として、Decision Log 0059時点で懸念されていたコントラスト比
  (紺#1c2438で約13.9:1)には及ばないものの、AAA基準(7:1)を再び
  上回る水準に戻った。

## 他の案

- 明度を段階的に下げた候補(L=0.40→契約比6.48、L=0.35→7.64、
  L=0.32→8.51、L=0.30→9.10)をあらかじめ算出し、そのうち
  「AAA基準をわずかに上回る、かつ変更前の#4c6cb3から見た目の
  変化が急激すぎない」バランスとしてL=0.35(#354c7d)を選んだ。
  より黒に近づけた候補(L=0.30以下)は、コントラスト比はさらに
  改善するが、当初の「夜空のような青」という発想(Decision Log
  0059)から離れて紺〜黒に近づきすぎると判断し見送った。

## 将来の変更可能性

- 引き続きプロジェクトオーナーの目視確認により、明度をさらに
  調整する可能性がある。

## Research Context

Decision Log 0059〜0062の一連の色調整は、「夜空のような青」という
直感的なイメージを、具体的なHEX値・コントラスト比という技術的な
制約とすり合わせていく過程そのものであり、この研究室が扱う
「調べること・記録すること・つくることを往復しながら、研究の過程を
ひらいていく」という姿勢を、色というごく小さな単位で反復している。
