# 0139. `/participate`を「実験室」に作り替え

- 日付: 2026-09-13
- 状態: 採用

## Decision

プロジェクトオーナーから、添付のUIモックアップ(LAB/実験室、「いま、
考えていること」3件、「持ち寄られたもの」空状態)を参考に、
`/participate`を「持ち寄る」から「実験室」に作り替える指示を受けた。
URLは`/participate`のまま、ナビゲーション表記のみ「持ち寄る」→
「実験室」に変更した。

### ページ構成

1. Hero(Eyebrow「LAB」・h1「実験室」・指定された本文)
2. 「いま、考えていること」(3件: 音の道/Fieldnote/研究断面をひらく。
   category・title・description・CTA「ふと思い出したことを寄せる →」)
3. 「ふと思い出したことを寄せる」(既存のFormspreeフォームを再利用)
4. 「持ち寄られたもの」(既存の`src/data/contributions.ts`・
   `visible`フラグの仕組みをそのまま使用)

### 「いま、考えていること」のデザイン

モックアップは書影・写真つきのカード風レイアウトだったが、指示に
「モックアップをそのままコピーする必要はない」「SNSや投稿掲示板には
見せない」「カードを大量に並べるUIにはしない」とあったため、写真は
使わず、既存の`/participate`「持ち寄られたもの」一覧
(`.contributionItem`)と同じ「細い罫線区切りの静かな一覧」に統一した。
3件固定を前提にしないレイアウト(Desktop幅でも横並びにしない、
縦積みのまま)にし、将来項目が増減しても崩れないようにした。

### フォーム

指定された2つの質問のみを本文の中心に置いた。

- 「何をふと思い出しましたか？」(必須、複数行のテキストエリア。
  指定された補足文をそのまま使用)
- 「どんなときに思い出しましたか？」(任意、短い1行入力。指定された
  補足文をそのまま使用)

「なぜ関係があると思ったか」のような理由を求める質問は入れていない
(明示的な指示)。お名前・メールアドレス・公開可否チェックボックス・
その説明文・`/privacy`へのリンクは、既存の「何かを持ち寄る」フォーム
(Decision Log 0128・0135)の仕様をそのまま踏襲した。honeypot・
Formspreeエンドポイント・fetchによる進行拡張の送信処理も変更して
いない。

### どのテーマから来たかの記録

3つの「ふと思い出したことを寄せる →」CTAは、共通のフォーム
(`#lab-contribute`)へ`?theme=sound`のようなクエリパラメータ付きで
リンクする。ページ読み込み時にクライアント側スクリプトがこのクエリを
読み取り、
1. 隠しフィールド`theme`の値を人が読める日本語ラベル(「音の道」等)に
   差し替え、Formspreeで受け取るメールにどのテーマから来たかが
   記録されるようにする。
2. フォーム上部に「「音の道」について送ります。」という確認テキストを
   表示し、送信者自身にもどの項目に反応して開いたフォームかが
   分かるようにする。

「持ち寄られたもの」の空状態からの一般的なCTA(`/participate#lab-
contribute`、テーマ指定なし)の場合は、この確認テキストは表示されず、
隠しフィールドは既定値(「実験室」)のままになる。

### 「持ち寄られたもの」の空状態

指定された文言(「いま考えていることを読んで、ふと思い出したことが
あれば寄せてください。」+「本 / 記事 / 場所 / 経験 / 誰かの言葉」+
CTA)のみを表示し、ダミー投稿・プレースホルダーカードは置いていない。
「最初のひとつを、ここから。」のようなタグラインも入れていない。
既存の`visibleContributions.length > 0`分岐はそのまま維持しており、
`src/data/contributions.ts`に運営が手動でエントリを追加すれば
(Decision Log 0128の運用のまま)、このセクションは自動的に一覧
表示に切り替わる。今回、管理画面や自動公開機能は実装していない。

## 対応

- `src/pages/participate.astro`: ページ全体を書き換え。
- `src/pages/participate.module.css`: 「いま、考えていること」用の
  `.ideaList`等、フォームの補足文用`.helper`、テーマ確認テキスト用
  `.themeNote`、空状態用`.contributionEmptyState`等を追加。既存の
  `.form`/`.field`/`.checkboxField`/`.privacyNote`等は変更していない
  (新しいフォームでも再利用)。
- `src/components/Header.astro`・`Footer.astro`: ナビゲーション表記を
  「持ち寄る」→「実験室」に変更(遷移先・項目数・順序は変更なし)。

## 気づいた点(今回は対応していない)

Home(`/`)の「持ち寄る」パネル(`src/pages/index.astro`、Decision Log
0125)は、見出し・本文・CTA文言とも「持ち寄る」のままで、リンク先の
`/participate`が「実験室」に変わったことで、導線の文言と遷移先の
印象がやや揃わなくなっている。今回の指示は`/participate`とナビ表記
のみが対象だったため、Home側は変更していない。プロジェクトオーナー
の判断で、Home側の文言(またはリンク先)を見直す場合は、別途指示を
いただきたい。

## 採用理由

「いま、考えていること」を`CurrentWorkList`(Home専用、Desktop幅で
横並びの2カラムに固定)ではなく、`.contributionItem`と同じ縦積みの
罫線区切りに揃えたのは、(1) 3件という項目数がHomeの2件固定と異なる
ため、横並び2カラムのコンポーネントをそのまま流用すると3カラムに
なってしまい、モックアップの「一覧」という見た目から離れること、
(2) 同じページ内の「持ち寄られたもの」と視覚的な語彙を揃えることで、
ページ全体の一貫性を保つため。

「どのテーマから来たか」をクエリパラメータ+クライアント側スクリプト
で実現したのは、このサイトが`output: "static"`のポータブルな静的
サイトであり(CLAUDE.md方針)、サーバーサイドでクエリを読むことが
できないため。同じ理由・同じ手法を、他のフォーム(お問い合わせの
「種類」select等)でもこれまで使ってきた進行拡張のパターンと合わせた。

## 他の案

3件それぞれに個別のフォーム(本棚の「一緒に読みたい」のような
per-item展開フォーム)を用意する案も検討したが、指示が「既存の送信
フォームを活用」と明記していたことと、3つの入り口から同じ2つの質問に
答える体験を、フォームを複製せず1つに統一する方が実装・保守ともに
単純なため、共通フォーム+隠しフィールドの方式を採用した。

## 将来の変更可能性

「いま、考えていること」の項目が増減した場合は、`ideas`配列と
`themeLabels`を更新するだけで対応できる(レイアウトは項目数に
依存しない縦積みのため崩れない)。将来、テーマごとに個別の詳細ページ
(例: `/lab/sound`)を作る場合は、今回のCTA(`?theme=`+アンカー)を
実ページへのリンクに差し替えるだけで移行できる。

## Research Context

「実験室」という名前と「いま、考えていること」という切り口は、
CLAUDE.mdの「研究は公開した瞬間に完成しない」という考え方を、
`/participate`という「持ち寄る」ための場所にも一貫させたもの。
以前の「何かを持ち寄る」という一般的な呼びかけから、「『ふ、と』が
いま何を試そうとしているか」を具体的に見せたうえで反応を募る形に
変えたことで、持ち寄る側にとっても「何を持ち寄ればいいか」の手がかりが
増え、単なる投稿フォームではなく研究室の内側を覗ける場所に近づいた。
