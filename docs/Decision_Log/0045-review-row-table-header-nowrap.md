# 0045. 研究断面詳細ページの行内の表で、見出し「便宜的な分類」も1行に収める

- 日付: 2026-08-16
- 状態: 採用中(Decision Log 0044の続き)

## Decision

`.row .table`のセル横paddingを`var(--space-2)`(1rem)から
`var(--space-1)`(0.5rem)に詰め、1列目の固定幅を`14.5rem`から
`13.5rem`に調整した。プロジェクトオーナーの「「便宜的な分類」も
一行にして」という指示への対応。

Decision Log 0044で1列目(「ふと」の用例)のセルを1行に収めたが、
2列目の見出し「便宜的な分類」はまだ2行に折り返されていた。表全体の
幅(20rem、Decision Log 0042)は固定のため、2列目に渡せる幅は
1列目の幅を削った分しか生まれない。横paddingを縮めることで
全体の余白を稼ぎ、1列目の幅も13.5remまで縮小して2列目に幅を回した。

## 採用理由

- 実測(Playwright経由)で、1列目のセル内容(「ふと立ち止まる、
  ふと振り返る」)に必要な幅は約199px、2列目の見出し
  (「便宜的な分類」)に必要な幅は約84pxだった。table全体の
  幅は320px固定のため、両方を1行に収めるには、paddingを
  詰めて余白を作る必要があった。
- 横paddingだけを`--space-1`に変更し、縦paddingは変更していない
  (行の高さ・余白のリズムは崩さない)。

## 他の案

- さらに文字サイズを縮小する案も検討したが、`--fs-sm`より小さい
  トークンがなく、新しいトークンを追加するよりpaddingの調整で
  対応する方がシンプルだった。

## 将来の変更可能性

- 02以降のReviewページで同様の表を使う場合、セル内容の長さに
  応じて1列目の幅・paddingの組み合わせを再調整する必要がある。

## Research Context

Decision Log 0044と同様、表・図版の外形サイズは変えず、内容の
見え方だけを細部まで調整する。
